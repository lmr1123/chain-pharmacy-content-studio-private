# 商品培训课件导出验证

本目录验证同一份结构化内容如何分别映射为视频场景、可编辑 PPTX 和静态 PDF。

## 共享边界

- `product-courseware-green.json` 保存审核状态、商品字段、页面类型、素材槽位和风格包绑定。
- 视频端后续读取相同字段，但使用时间轴和视频布局参数。
- PPTX 端将文字、表格、色块和素材槽位导出为原生可编辑对象。
- PDF 端使用 PPTX 的确定性静态状态，不承诺动画。

## 当前限制

- 用户提供的参考目录只有 5 张截图，没有可继承的 PPTX 母版。
- 截图用于版式和内容转录；未将整页截图或截图裁切资产放入生产课件。
- Logo、商品包装、联合用药包装和注意事项插图仍是可替换素材槽位。
- 参考文案需要内部药师或合规人员复核后，才能把 `content_lock` 升级为正式审核稿。

## 正式内容入口

- 默认入口改为 `text-word-import/import_courseware_content.py`：一份文本或 Word 对应一个商品，批量时一次提供多个文件或目录。
- 自动识别商品介绍、核心卖点、适宜人群、联合用药、品种对标和注意事项；结构化 JSON 只在系统内部使用。
- 缺失字段保持空白；无法可靠归类的原文进入 `unmapped_content`；完整原始段落和表格同时保存在 `source_blocks`，避免整理过程丢失来源内容。
- Excel 多表输入已降为历史技术验证，不再作为正式用户操作流程。

## 品牌升级签样

- `work/build-brand-upgrade.mjs` 继续复用同一个绿色风格包，不另建与品牌冲突的新风格。
- 当前签样覆盖品牌封面、商品介绍/卖点/人群页和联合用药决策页。
- 核心卖点、适宜人群和联合用药均按数组输入；超过单页容量时自动续页。
- 升级目标是改善信息层级、留白、字体和表格表达，同时固定保留大参林品牌绿、品牌名称及内部学习声明。
