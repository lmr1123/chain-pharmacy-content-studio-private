# 健康科普 Seedance 模式 · 业务怎么用

**模式名：** 健康科普视频 / Seedance 科普 / 视频号科普<br>
**模式 ID：** `seedance-health-edu-v1`<br>
**更新：** 2026-08-08<br>

适合：对外**视频号 / 短视频**生活健康与安全常识科普。<br>
**不适合：** 店员内部培训的「疾病科普 MG 片」（那条请说「疾病科普视频」）。

---

## 你只要记住四步

```text
① 拉最新仓库 / 安装
② 说「做健康科普视频」+ 主题一句话
③ 先审《科普脚本复核包》→ 确认后出 Seedance 分段提示词
④ 复制提示词到 Seedance 2.0 / 即梦出片；用发布全家桶发视频号
```

**关键点：**<br>
本模式默认交付的是**可复制提示词**（不是本机直接出的培训 MP4）。出片在你的即梦 / Seedance 账号里完成。

## 第 2 步 · 选用模式并给主题

任选一种说法：

```text
做一条健康科普视频，主题是：×××。目标人群：×××。
```

```text
用 Seedance / 即梦出视频号科普。主题：×××。用元提示词扩展脚本。
```

```text
健康科普 Seedance 模式。主题：居家防跌倒 / 春季舒压 / 暴雨出行……
```

能多给更好（可选）：场景（厨房/玄关/街头）、想强调的一句干货、情绪词（别硬冲/慢一点）。

---

## 第 3 步 · 审脚本（确认前只是草案）

代理会给你 **《科普脚本复核包》**，至少包含：

| 材料 | 你看什么 |
|------|----------|
| **5 拍剧本** | 钩子 / 干货 / 演示 / 扩展 / 结尾是否顺 |
| **口播台词** | 是否口语、有没有吓人过度或像诊疗 |
| **合规** | 无白大褂、无医疗器械、无病理术语；生活常识表达 |
| **角色与场景** | 服装色块、主场景是否合适 |

### 你需要回复的确认句（示例）

```text
脚本通过。可以出 Seedance 提示词。
```

或：

```text
第 2 拍口播改成……；结尾转发给「家里老人」。确认后再出提示词。
```

---

## 第 4 步 · 复制到 Seedance 出片 + 发布

确认后你会收到：

1. **`02-Seedance提示词-分段.md`** — 每段单独复制到 Seedance 2.0 / 即梦<br>
2. **`03-视频号发布全家桶.md`** — 标题、免责置顶、转发语<br>

### 即梦使用提示（业务侧）

- 建议比例：**竖屏 9:16**<br>
- 每段时长：**约 10–15 秒**（平台单次上限 15 秒）<br>
- **不要上传写实真人脸**参考图；本模式是 3D Pixar 风，纯文本即可<br>
- 多段可「视频延长」衔接，或分段生成后剪辑拼接<br>

### 免责置顶（默认）

```text
⚠️ AI 生成技术辅助创作。本视频仅供生活常识分享，非专业医疗或应急决策建议。平安第一。
```

## 和「疾病科普视频」的区别

| | 健康科普 Seedance | 疾病科普视频（内部培训） |
|--|-------------------|--------------------------|
| 给谁看 | 大众 / 视频号 | 店员培训 |
| 你拿到什么 | Seedance 提示词 + 发布文案 | 本机 MP4 培训片 |
| 画面风格 | 3D Pixar 生活场景 | 医疗科技蓝 MG 金样 |
| 怎么说 | 「健康科普视频 / Seedance」 | 「疾病科普视频」 |
