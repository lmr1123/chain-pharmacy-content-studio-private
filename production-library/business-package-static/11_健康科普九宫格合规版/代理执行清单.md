# 九宫格合规版 · 代理执行清单

权威：`docs/jiugongge-health-edu-compliance-mode.md`<br>
资产：`production-library/templates/prompt-modes/jiugongge-health-edu-compliance-v1/`

## 闸门

- 输出 0 命中：医生/白大褂/医院/诊室/器材/预防/治疗/缓解/病名<br>
- 确认前只交复核包<br>
- 默认不调用付费 API<br>
- 勿与原版 `jiugongge-health-edu-v1` 混角色<br>

```bash
# 复核阶段：只生成合规复核包与 approval.json
python3 scripts/scaffold_jiugongge_health_edu_compliance.py --vars <json>
# 业务明确确认后；代理填写 approved=true / approved_by，保留 input_sha256 与 review_sha256
python3 scripts/scaffold_jiugongge_health_edu_compliance.py --vars <json> \
  --release --approval <输出目录/approval.json>
```

变量 JSON 或复核稿在审批后改变时，hash 门必须拒绝发布；终稿禁词命中时也必须拒绝。
