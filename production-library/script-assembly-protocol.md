# 审核脚本驱动的自由组合生产协议

## 目标

业务提交的是审核后的培训脚本，不是固定模板字段。系统保持原文顺序，将每个语义章节识别为叙事意图，再选择同一风格包下的场景配方。页面数量、场景顺序和是否出现某类场景由脚本决定。

稳定不变的是视觉语法，不是页序：

- 一个项目只绑定一个 `style_pack_id`；
- 母版、字体、色板、字幕、音色、角色身份、转场和运动节奏由风格包控制；
- 布局和动画来自可参数化的 `scene_recipe_id`；
- 疾病、器官、症状、商品和证据来自带 `series_id`/来源状态的资产；
- 审核文字只进入内容槽位，不在装配阶段自动改写。

## 生产链路

1. 导入 Word、Markdown 或自然文本，保留原文和章节顺序。
2. 识别章节意图；低置信度章节进入“待选择场景”队列，不自动猜医学含义。
3. 依据风格包筛选兼容的场景配方，按信息量自动续镜，而不是压缩字号。
4. 查询组件和系列素材；已有成员直接复用，缺失成员生成素材任务。
5. 新系列先签一张代表图；已有系列新增成员仍独立完成来源、视觉、技术和医学审核。
6. 生成分镜清单和缺口清单，业务只确认异常项与关键图，不逐镜从零定制。
7. 自动生成配音、字幕和动画，业务可局部换配方、换素材或调整时长。
8. 完整 QA 后导出 MP4/PPTX/PDF，并把批准的新成员回写公共库。

## 自由组合的约束

- 允许任意省略、重复和重排语义章节。
- 不允许跨风格包混用母版、字体、字幕或运动语法。
- 每镜头只有一个主要运动焦点。
- 角色站位、信息密度和图片子风格必须满足配方约束。
- 真实商品包装、Logo、说明书和证据图只能使用授权原图。
- 无匹配配方时先进入人工选择；确认是普遍需求后才新增配方，禁止复制主题工程改名。

## 三层复用模型

1. **风格层**：品牌母版、设计令牌、字幕、音色、转场和镜头节奏。
2. **场景配方层**：症状分组、机理演示、证据累积、建议列表、总结矩阵等布局与动画契约。
3. **主题素材层**：人体、器官、症状、草本、商品、证据和环境介质系列成员。

主题不同只会改变场景序列、内容槽位和素材成员；三层共同约束保证最终画面属于同一系列。

## 业务界面应只暴露

- 上传审核脚本；
- 选择课程类型与主风格包；
- 上传公司授权素材；
- 查看自动分镜与缺口提醒；
- 对低置信度章节选择一个建议配方；
- 局部返修并导出。

组件 ID、提示词、锚点和动画参数属于制作系统内部能力，不要求业务人员填写。
