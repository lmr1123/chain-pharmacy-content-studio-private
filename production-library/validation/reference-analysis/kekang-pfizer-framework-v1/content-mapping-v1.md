# 可可康灵芝胶囊 × Pfizer 叙事配方内容映射 v1

> 状态：validation 内容结构分析；不是审核稿、正式分镜、模板或 `style_pack`。  
> 日期：2026-07-31。  
> 目标：判断现有可可康内容能否进入 Pfizer 案例提炼出的 F01–F10 场景配方，并形成不依赖原创审美的完整课程骨架。

## 1. 执行结论

现有可可康内容可以覆盖 Pfizer 叙事语法中的 **9/10 类配方**，足以形成一条约 3–4 分钟的完整课程骨架；但目前只能进入**结构评审**，不能进入正式旁白和动画生产。

原因不是缺少设计，而是内容与资产门禁尚未满足：

- 公司内部 PPT 已归档，但主题登记仍是 `medical: pending-pharmacist`。
- PPT 中存在降血压、预防心血管疾病、抗肿瘤、长期服用依赖、联合用药、服用周期等需要药师／合规重新确认的表述。
- 可可康及三款联合用药商品只有课件截图，没有授权高清包装和说明书终稿。
- 现有 v7 把视频模板 `template.product-training-faithful-v1` 与 PPTX 风格包 `style-pack.dashenlin-courseware-green-v1` 混绑，不能作为正式绿色视频金样。

因此本轮锁定的是**内容骨架**，不是视觉成片：先让业务／药师确认哪些内容可以讲，再按 Pfizer 的成熟教学语法完整复刻一条绿色视频金样。

状态标记：

- `SOURCE-ALIGNED`：与内部 PPT 对齐，但仍待药师／合规确认。
- `ASSET-BLOCKED`：内容可定位，但缺授权高清素材。

## 3. 模板与风格绑定判断

### 当前登记有效绑定

```json
{
  "template_id": "template.product-training-faithful-v1",
  "style_pack_id": "style-pack.reference-product-blue-v1",
  "theme_id": "theme.product.kekang-lingzhi-capsule"
}
```

这是生产库中可可康当前唯一兼容绑定，但用户已否定继续以浅蓝样式扩展绿色可可康方向，因此本轮不据此制作新片。

### 现有 v7 的绑定问题

```json
{
  "template_id": "template.product-training-faithful-v1",
  "style_pack_id": "style-pack.dashenlin-courseware-green-v1"
}
```

该组合把视频模板与 PPTX 课件风格包混用；绿色风格包只验证过 PPTX／PDF，没有对应的完整用户签样视频。它可以提供大参林绿色、白底、字体和品牌母版测量值，不能直接宣称为绿色视频 `style_pack`。

### 本轮决定

- 内容映射保持**视觉中立**，不创建新风格包。
- Pfizer 案例作为“机制比较型叙事候选金样”。
- 若业务确认走绿色视频，下一步应完整制作并签样一条绿色可可康视频；通过后再登记唯一绿色视频 `style_pack_id`。
- 在此之前不得继续使用“蓝色视频模板 + 绿色 PPT 风格包”的混绑配置。

结论：不使用 F05 是正确的框架适配，而不是缺镜头。成熟框架的价值在于约束表达，不是要求每个主题机械填满所有配方。

## 6. 与现有 v7 的关系

现有 v7 的 16 场内容并非全部无效，以下部分可以保留为结构输入：

- 三类成人状态而非儿童形象。
- 数字人承担提问、指向、解释、总结，不常驻角落。
- 原料 → 工艺 → 生产的产品特点路径。
- 三类状态 → 三大产品方向的回扣。

需要停止沿用的部分：

- 深绿色电影式开场、薄荷绿课件卡、金色装饰、药师数字人等多套视觉语法混用。
- 在没有审核口径时自行设计体内机制、免疫盾牌、肝脏保护层等确定性效果。
- 把短样片通过当作完整课程通过。
- 将 PPTX 绿色风格包直接绑定到视频模板。

## 7. 素材与审核缺口

### 业务／合规必须提供

1. 可直接用于旁白和上屏的审核终稿，明确保留／删除／改写 PPT 中高风险表述。
2. 可可康灵芝胶囊说明书或批准信息终稿。
3. 对 9.13g/100g、专利提取、GMP、生产技术等卖点的可用证据和展示范围。
4. 三套联合用药及“长期容易依赖”等话术的药师／合规结论。
5. “1 个月一个周期、连续 2–3 个月”的批准口径。

### 业务必须提供的授权资产

- 可可康灵芝胶囊高清正面／多面包装。
- 谷维素片、护肝片、转移因子口服溶液高清授权包装。
- 大参林 Logo、中山可可康工厂／生产线／GMP 材料。
- 若需要展示大别山产地或专利工艺，提供公司可用的原始图片／视频／证书。

### 制作侧可以在审核前完成

- 18 镜结构评审与场景时长估算。
- 空白器官／路径／角色的运动配方原型，但不填医学断言。
- 白底、黑线、品牌绿、症状红、过程青的语义色测试帧。
- 产品和证据全部使用明确标记的空槽，不使用截图包装或 AI 仿包装。
