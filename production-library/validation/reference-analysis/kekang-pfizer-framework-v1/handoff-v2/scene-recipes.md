# 动态场景配方与画面设计合同

## 全局画布

- 1920×1080，30fps，安全边距 96px。
- 背景：奶油白 `#FBFAF5`；浅薄荷绿 `#EAF5ED`。
- 主绿 `#07863F`；深绿 `#103F2D`；暖金 `#C89532`。
- 主标题 64～84px；镜头标题 52～64px；标签 36～48px；字幕 42～48px。
- 单镜头最多一个主标题、一个主视觉、三个短标签；不得放整段讲义。
- 标题只在进入时承担定位，1～2 秒后让位给视觉主体。
- 所有镜头必须从前镜继承至少一个视觉锚点：主体、轨迹、颜色或位置。

## R01 `hero_reveal`

用途：K01、K07、K18 的产品／品牌聚焦。

- 构图：主视觉占画面 38%～46%，标题占 24%～32%，其余为环境留白。
- 图层：背景、环境光形、主视觉、标题、短标签、路径或光环。
- 进入：环境先出现；主视觉遮罩上揭示＋轻微尺度回弹；标题侧向进入。
- 表演：主视觉稳定，光环或局部高光低强度循环；标签随旁白依次出现。
- 退场：标题先退，主视觉缩小并移动到下一镜锚点；禁止整页淡出。
- 禁止：包装截图铺满画面、固定封面页停留超过 2.2 秒。

## R02 `life_context_sequence`

用途：K02–K05 的生活状态建立。

- 构图：环境占全屏，人物位于左右三分线，状态符号靠近动作区域。
- 图层：远景环境、中景人物、前景物件、状态符号、短字幕、环境运动。
- 进入：先出现生活情境，再局部推近人物动作，不先展示结论卡。
- 表演：时间、姿态、表情、物件或天气至少有一项周期运动。
- 退场：人物／状态符号沿运动方向退出；保留一个颜色或轨迹进入下一镜。
- 禁止：三个人物并排静态陈列、症状表格、人物卡片一屏铺满。

## R03 `multi_node_focus`

用途：K02、K06、K15 的三类总览。

- 构图：三个节点沿弧线或深度轴分布，当前节点最大，其他节点降低饱和度。
- 进入：节点按 01→02→03 依次进入，每个间隔 0.25～0.45 秒。
- 表演：焦点依旁白依次切换，非当前节点透明度 0.62～0.78。
- 退场：三个节点沿路径汇聚成一个章节锚点，而不是整页切走。
- 禁止：三栏等宽卡片从头到尾静止。

## R04 `central_split_orbit`

用途：K08 两类成分、K11 成分关系。

- 构图：中央主体 32%～38%，两条路径向左右不同高度分化。
- 进入：主体先完成，再绘制路径，再依次出现标签。
- 表演：两个标签轮流聚焦；虚线轨道缓慢旋转或呼吸。
- 退场：其中一个标签扩大成为下一镜主体，另一标签缩入导航位。
- 禁止：左右分栏文字说明、两个静态文本框。

## R05 `pathway_explain`

用途：K09、K10、K11 的批准路径解释。

- 构图：左侧来源、中央过程、右侧输出；同一时刻只突出一个过程节点。
- 进入：来源主体进入，路径逐段绘制，过程节点按旁白出现。
- 表演：光点或材料 token 沿已批准路径移动；结果只在路径完成后出现。
- 退场：结果标签移动到 K11 的关系图位置。
- 禁止：自行添加受体、靶点、细胞结合、吸收倍数和确定性治疗前后对比。

## R06 `evidence_zoom`

用途：K07、K12、K14 的批准信息／证据聚焦。

- 构图：授权素材为主视觉，数字或短结论作为局部放大层。
- 进入：先展示素材上下文，再对证据位置做局部放大；不要一开始就全屏大数字。
- 表演：放大框、测量线或高亮带只围绕一个证据点运动。
- 退场：证据点缩成标签，进入下一条特点。
- 禁止：低清 PPT 截图、无来源数字、伪造证书或工厂。

## R07 `process_conveyor`

用途：K13 双重提取。

- 构图：原料、第一次提取、第二次提取、胶囊成形沿折线路径排列。
- 进入：灵芝原料先进入；材料 token 随旁白依次经过各阶段。
- 表演：当前阶段局部放大 1.04，其他阶段降低透明度；过程液体或粒子只作示意。
- 退场：胶囊剂型移动到 K14 质量检查区。
- 禁止：把四步骤做成静态流程图并停留全程。

## R08 `product_pair_relation`

用途：K15、K16 联合应用。

- 构图：问题状态在前景建立；商品 A／B 从两侧进入；关系符号在中心生成。
- 进入：先问题，再商品 A，再商品 B，最后关系与注意事项。
- 表演：两商品各自承担一个获准作用标签；不得同时出现整段话术。
- 退场：当前组合沿深度轴退后，下一组合从相同轨迹进入。
- 禁止：联合用药表格、三套组合同时铺满、AI 仿包装。

## R09 `calendar_progression`

用途：K17 服用周期。

- 构图：月历占中心，1→2→3 月沿时间轨迹推进。
- 进入：第 1 月先出现，再翻页或沿轨迹推进至第 2／3 月。
- 表演：当前月份高亮，注意事项在终点出现。
- 退场：时间轨迹弯成 K18 总结环形路径。
- 禁止：擅自添加剂量、频次、疗程结果。

## R10 `summary_convergence`

用途：K18 六维总结。

- 构图：六个短标签围绕中央产品／灵芝主体分布。
- 进入：标签按课程出现顺序快速回放，不能一次性显示表格。
- 表演：当前标签依次聚焦；路径逐步收束到中央主体。
- 退场：标签淡出但主体保留，品牌封底从主体位置展开。
- 禁止：整页总结表停留、未审核结论重新出现。

## 转场连续性

相邻微镜头必须使用下列一种承接：

1. **主体承接**：前镜主体缩小／移动到下一镜起始位置。
2. **路径承接**：前镜路径延长成为下一镜构图轴。
3. **颜色承接**：当前强调色扩散为下一镜背景光形。
4. **标签承接**：当前结论标签扩大成为下一镜标题。
5. **声音承接**：转场音跨越剪切点 80～160ms，画面不得同时硬切。

禁止连续使用两次整页淡入淡出。
