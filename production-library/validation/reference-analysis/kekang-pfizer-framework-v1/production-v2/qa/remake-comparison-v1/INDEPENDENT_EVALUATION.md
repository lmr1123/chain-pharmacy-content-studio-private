# 可可康 production-v2 独立评价与整改建议

日期：2026-08-01  
评价对象：`renders/kekang-green-microshot-animatic-v2.mp4`  
参照方法：Pfizer 案例的“同一教学模型持续演进、动作表达动词和因果、画面承担解释、声音驱动时序”

## 结论

当前全片不适合作为可扩展金样，应退回重做视觉叙事层。它在分辨率、解码、微镜头编号、
entry/performance/exit 文件等工程项目上合格，但核心仍是“固定课件版式中替换标题、图片和少量节点”，
没有达到参考案例依靠连续视觉状态讲清知识的标准。它可以保留为结构草稿，不能据此批量换商品。

## 实际播放后的主要问题

| 维度 | 当前表现 | Pfizer 方法要求 | 影响 |
|---|---|---|---|
| 教学主体 | 每镜重置为标题、说明、门禁标签、底部字幕和一个小素材 | 一个场景或模型持续存在，旁白每推进一句就改变一个关键变量 | 观众看到页面切换，未看到知识形成 |
| 动作语义 | 人物轻移、光圈呼吸、圆点沿折线移动 | “醒来、再次入睡、提取、浓缩、输出”等动词必须被真实演出 | 有运动但没有解释力 |
| 画面层级 | 标题和说明长期占据主要注意力 | 图像／模型是主讲者，文字只补充结论 | 观感像 PPT，而不是培训动画 |
| 连续性 | 微镜头之间整体重置，前一镜结果很少成为后一镜输入 | 起始状态 → 操作 → 结果，结果继续进入下一步 | 因果链被切断 |
| 声音 | 全片主版本为静音结构片，时长按占位合同生成 | 正式旁白先锁定，动作点跟随真实语音和关键音效 | 动画节奏与语言动词脱节 |
| 质量验证 | 验证 ID、三帧存在、非文字层有位移、无黑场 | 验证三帧是否出现不同的“教学状态”以及是否对应旁白 | 技术通过掩盖内容失败 |

旧版抽检结果：K03 的人物小图在通用画布中淡入淡出，三个时间词变成标签；K13 只是金色圆点在折线上移动；
K16 是商品 A/B 空槽；K18 是节点卡与空品牌槽。K08 有声音和路径基础，可作为技术资产保留，
但不能证明整套叙事语法成立。

## 为什么上一轮“方案完整、执行仍差”

1. 交付合同定义了微镜头数量和通用 recipe，却没有为每句旁白定义“开始状态、语义动作、结束状态”。
2. 在首个金样尚未成立前就抽象 R01–R10 和一个全局共享图层池，执行模型自然优先复用同一骨架。
3. 58 镜一次性铺开，导致精力用在覆盖率而不是代表片段的审美和叙事闭环。
4. 正式声音没有先进入主时间线，镜头时长只能按占位值完成，动作无法准确落在语言动词上。
5. QA 只证明“像素发生变化”，没有证明“观众从变化中理解了什么”。

## 哪些保留，哪些推倒

- 可保留：绿色／奶油白／少量金色的候选色彩、部分插画、药师参考音色、渲染与混音管线、
  微镜头 ID 和时间码基础设施。
- 必须推倒：全局通用卡片布局、用圆点／轻移代替语义动作、每镜都出现的标题／门禁／底栏组合、
  先批量铺 58 镜再验收的流程。
- 暂不进入：正式商品包装、品牌 Logo、专利和疗效宣称；这些继续使用真实业务证据门禁，不能伪造。

## 两段整改证明

### K03 失眠状态

- 原版：人物只是小图卡；“入睡困难、夜醒、早醒、次日疲倦”被拆成标签或标题。
- 调优版：同一个卧室和同一女性贯穿全段；眼部提示入睡困难，时钟和 1:00/3:00/5:00 路径表现
  反复醒来；夜色变晨光后，人物坐起扶额，直接演出白天仍然疲倦。前一句的结果成为下一句的起点。
- 声音：11.618 秒正式药师旁白，字幕与动作时码同源，母带约 -16.0 LUFS、True Peak -2.0 dB。

### K13 双重提取工艺

- 原版：两枚节点标签和一条折线，圆点移动无法说明材料发生了什么变化。
- 调优版：灵芝原料颗粒进入第一次提取罐，提取物沿管路进入第二次浓缩罐，液位和颜色变化，
  最后形成胶囊输出；画面和声音均不再出现制作解释、证据门禁或“资料为准”等内部提示，右上角
  只保留弱化的“模板示例”。
- 声音：11.382 秒正式药师旁白，字幕与动作时码同源，母带约 -16.0 LUFS、True Peak -1.6 dB。

### K16 三套联合方案关系

- 正式版：三套方案共用一个持续关系舞台；每套先建立失眠／肝功能异常／免疫力低下场景，再让
  两个商品角色从两侧进入、连接并形成方案结果；已完成结果保留在顶部轨迹并承接下一套。
- 素材边界：只使用公司课件中的商品搭配名称；未授权包装不进入画面，以程序化商品角色表达，
  不扩写剂量、机制、疗效或销售话术；右上角只保留“模板示例”。
- 声音：20.237 秒正式药师旁白，成片 20.200 秒；母带 -16.0 LUFS、True Peak -1.1 dB。ASR
  首次将同音术语误识，使用谷维素片、灵芝胶囊、护肝片、转移因子口服溶液领域提示后全部正确。

## 后续完整整改方案

1. 先锁正式旁白和证据状态，再画分镜；禁止以静音占位时间直接制作正式动画。
2. 每个微镜头强制填写六项语义合同：旁白句、核心动词、开始状态、画面操作、结束状态、下一镜继承物。
3. 先做三类代表金样：人物情境、机理／工艺、商品组合决策；逐段审过后再抽象模板。
4. 模板只抽象可复用槽位，不抽象内容本身。人物情境、工艺流程、商品对比应拥有不同的场景组件。
5. QA 增加“静音可理解”和“首中尾状态”检查：三帧必须展示不同教学状态，而不仅是位置或透明度变化。
6. 完整金样通过后再扩主题；未通过前不得以镜头覆盖率或文件数量宣称可批量生产。

## 新金样最低验收线

- 每句关键旁白至少对应一个可辨识的视觉状态变化；核心动词必须由主体动作表达。
- 同一知识链中的对象持续存在，上一镜的结果可见地进入下一镜。
- 关闭声音后，审片人仍能复述主要过程；只看字幕时不依赖大段正文才能理解。
- 正式旁白、字幕、动作点和音效使用同一份时间码；不得截断尾音。
- 三帧 QA 由审片人回答“发生了什么变化”，若只能回答“元素移动／变亮”，该镜失败。
- 代表金样经业务确认前，不扩展到其他商品主题。
