K03 · 失眠状态

从“小人物卡 + 三个标签”，改为同一女性在夜间与白天之间的连续时间和状态变化。

左：原执行版右：正式调优版（含正式声音）
原版缺口人物、时钟和症状没有构成同一事件，只是轮流显示。
调优动作眼部提示 → 时钟推进 → 1/3/5 点夜醒 → 晨光 → 白天坐起仍疲倦。
为什么更好每句话都改变同一场景，观众能看到因果，不需要读说明文字。

K13 · 双重提取工艺

从“圆点走折线”，改为原料在两次加工中的真实状态变化。

左：原执行版右：正式调优版（含正式声音）
原版缺口节点亮起只说明先后顺序，没有解释提取与浓缩。
调优动作原料入罐 → 第一次提取 → 管路转移 → 二次浓缩 → 胶囊形成。
为什么更好材料是持续的教学主体，颜色、液位、位置变化都具有含义。
