# 其他模型零起点独立制作盲测

## 0. 这份测试回答什么

本测试只回答：一个没有看到 Codex 整改实现的模型，能否从业务内容和公开参考案例出发，独立完成
脚本、视觉设计、素材、正式声音、动画、渲染与 QA。

它不用于正式批量生产，也不允许模型复用当前整改版。通过这次测试仍不代表可稳定跨商品扩展；
后续还需要一个未见过的新商品／新场景泛化测试。

## 1. 可信盲测的前提

### 必须隔离

1. 使用一个全新模型任务／全新对话，不继承此前 K03、K13 的执行记录。
2. 将工作区切换到一个干净目录，只放“允许输入”。不要把
   `chain-pharmacy-content-studio` 整个工程作为它的工作区。
3. 模型不得访问 Codex 整改成片、源代码、派生图片、语音、时码、接触表、独立评价和上一份执行合同。
4. 第一次最终成片交付前，不给人工构图或动画修改意见；允许模型自行播放并最多返工两轮。
5. 保存完整提示词、模型名称／版本、工具环境、执行日志和全部输出，避免只保留最好的一次。

如果仍在旧对话或共享全工程中运行，这次结果会受到信息泄漏影响，不能叫零起点测试。

## 4. 给模型的任务

模型需要独立完成两个 10～18 秒的正式片段：

1. 自己观看并拆解 Pfizer 参考，说明借鉴的是叙事方法，而不是复制品牌视觉。
2. 根据业务事实独立撰写自然旁白；不得添加未给出的医学或商品结论。
3. 独立设计两段不同的视觉表达，生成或绘制所需素材。
4. 独立生成中性、可信的中文药师旁白、字幕、环境声和克制的关键音效。
5. 编写动画、渲染 MP4、实际播放、抽帧检查并自主返工。
6. 输出设计说明和证据边界说明。

片段必须是动画视频，不接受 PPTX、静态网页翻页、静态图片轮播或仅靠镜头缩放的 slideshow。

## 5. 只给目标，不给解法

为避免把 Codex 的设计偷偷交给模型，本盲测只提供以下教学目标：

- 片段 A 播放后，观众应能复述“入睡困难、夜间反复醒来／早醒、次日疲倦”之间的连续关系。
- 片段 B 播放后，观众应能复述“原料先提取、再浓缩”的材料过程，并意识到额外宣称需要证据。
- 关闭字幕后，主要关系仍应能从画面理解。
- 两段不能使用同一个页面骨架换文字和图片。

不要告诉模型应该使用卧室、时钟、时间节点、提取罐、管路、液位或胶囊；这些属于它需要独立完成的设计判断。

## 6. 输出要求

模型自行建立输出目录，必须交付：

- 两段最终 MP4，1920×1080、30fps、H.264/AAC；
- 两段独立旁白 WAV、SRT／VTT；
- 每段至少 8 个均匀时刻接触表；
- 源工程和一条可复现渲染命令；
- `DESIGN_RATIONALE.md`：为什么这样设计、从 Pfizer 学到了什么；
- `EVIDENCE_BOUNDARY.md`：哪些事实有输入依据、哪些内容因无证据而没有表达；
- `QA_REPORT.md`：完整解码、黑场、响度、峰值、字幕安全区、播放检查和自主返工记录。

## 8. 人工盲评方法

不要让制作模型给自己打最终分。将模型版本与 Codex 版本随机改名为 A／B，由至少两位不了解来源的
审片人分别观看；第一次观看不显示字幕，第二次再开启字幕。

| 维度 | 权重 | 评什么 |
|---|---:|---|
| 教学理解 | 25 | 看完能否正确复述知识和因果 |
| 语义动作 | 20 | 动作是否表达具体动词，而不是装饰运动 |
| 视觉设计 | 15 | 构图、层级、风格一致性和非 PPT 感 |
| 连续叙事 | 15 | 前一步结果是否成为下一步输入 |
| 声音与节奏 | 15 | 旁白自然度、字幕、动作同步和混音 |
| 合规与可追溯 | 10 | 是否克制、无虚构、源工程可复现 |

通过标准：总分至少 80／100，教学理解和语义动作均不得低于各自权重的 75%；两位审片人的总分差异
大于 12 分时，需要第三位审片人。出现虚构医学／商品证据、无声音、静态翻页、无法复现渲染中的任一项，
直接失败。

## 9. 不能只测一次

一次成功只能说明“这次做到了”，不能说明业务可以稳定使用。最低可靠性测试：

1. 同一简报用同一模型开两个全新任务独立运行，检查结果是否都达标；
2. 再给一个此前从未出现的新商品／新知识场景，不提供任何 Codex 成片；
3. 三次中至少两次达到 80 分，且没有硬失败，才可认为模型具有可用的独立制作能力；
4. 三次都需要大量人工逐镜修改，则它只能作为制作助手，不能作为业务自助生产方案。

## 10. 生产路线判断

### 不建议：让任意模型每次从零做整片

这种方式适合能力测试和探索，不适合业务稳定交付。模型、版本、工具和随机性变化都会造成风格与质量漂移。

### 也不够：只给一条金样视频，让模型“照着拓展”

视频只展示结果，没有给出可执行的布局、动画状态、内容槽位和声音时间线。模型会猜模板规则，容易重新
退化成 PPT 页面。

### 建议：把签样金样变成模型无关的生产系统

1. 金样成片：定义最终质量。
2. 可执行模板：沉淀人物情境、流程机理、商品组合等场景组件。
3. 结构化输入：业务只提交审核文案、商品图、证据和场景类型。
4. 模型做规划：将文案映射到场景和内容槽位，生成旁白草案和资产需求。
5. 确定性渲染：由固定模板、TTS 和渲染器生产，不让模型每次重写整套动画。
6. 自动 QA＋人审：技术自动化，教学语义和合规由人确认。

这样业务不依赖 Codex，也不依赖某个特定模型。模型可以更换，真正稳定的是模板运行时、输入协议和验收门禁。
