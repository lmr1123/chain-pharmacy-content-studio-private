## 返工记录

### K03 第 1 轮

- **问题**：S01 动画时长超出 cue 边界，导致 S02 entry 仍残留 S01 字幕与眼环；成片约 12.13s 偏长。
- **修改**：引入绝对时码 `advanceTo(cue.end)`；压缩 S01 动作；眼环在 S02 前清掉。
- **结果**：成片 11.733s / 352 帧；S02 entry 仅见 1:00；字幕与旁白对齐。

### K13 第 1 轮

- **问题**：S03 胶囊与证据出现过早，浓缩「收束→输出→证据」分步不够清晰；S01 entry 空罐建立偏慢。
- **修改**：S01 加快空罐建立；S02 拆成「建罐 → 转移 → 升液」；S03 强制顺序：浓缩收束 → 胶囊 → 证据最后。
- **结果**：S03 entry 仅见浓缩液、无证据；证据仅在后段出现。
