# 金样细节复刻门禁（防再犯）

用户 2026-08-02 纠正：框架对齐 ≠ 细节复刻。后续每镜必须过本清单，**未过不得称金样**。

## 0. 分层原则（强制）

| 层 | 实现方式 | 禁止 |
| --- | --- | --- |
| 主视觉角色/实物/气泡壳/病毒形 | AI 生图或正式位图，**透明 PNG** | SVG 火柴人、PIL demo、带白底方卡 |
| 可编辑文案 | 程序化 `Txt` 叠在图上 | 把关键字烧进插画（除非装饰） |
| 导航/标题/表格 | 程序化，但字号/字重对齐参考展示体 | 正文小号「文档体」硬当标题 |
| 包装/Logo | 业务授权槽位 | 参考视频裁切 |

**「SVG 做不出来」→ 生图做壳 + 文字层叠加。** 这是默认升级路径，不是例外。

## 1. 每镜开工前（对照参考同秒帧）

- [ ] 截参考帧 + 标出：标题区、导航、主图、角标、字幕基线
- [ ] 量字号相对高度（标题约占画面高度比例）
- [ ] 记入场：方向 / 旋转 / 缩放起点 / 是否倾斜
- [ ] 记图标形态：气泡？病毒刺？丝带？非通用圆角矩形

## 2. 资产入库前

- [ ] 透明通道：四角 alpha=0，主体 mid alpha≈255
- [ ] **在丝绸背景上预览**（禁止只在白底看图）
- [ ] 无白/灰方卡底板残留
- [ ] 无参考水印/Logo 像素

## 3. 字号字重（1080p 默认下限）

| 角色 | 建议下限 | 字重 |
| --- | --- | --- |
| 封面主标题 | 72–88 | 900 |
| 章节丝带 | 44–52 | 900 |
| 导航 pill | 28–32 | 900 |
| 卡片主句 | 36–42 | 900 |
| 气泡强调 | 44–52 | 900 |
| 底字幕 | 38–42 | 900 |
| 表格正文 | 26–30 | 800+ |

字体优先展示黑体族（HarmonyOS Black / Source Han Heavy），**禁止**只用常规 PingFang 当主标题。

## 4. 动效

- [ ] 与参考同语义对象有独立入场（非整页 fade）
- [ ] 倾斜气泡：初始 rotation ≠ 0，scale 从小到大
- [ ] 导航 active 色切换与旁白同步
- [ ] 起/中/末 三帧与参考并排

## 5. 验收输出

- [ ] `qa/pair/` 关键秒并排
- [ ] 50% 缩放仍可读主标题
- [ ] 交付说明写清：参考原声 / 包装槽位 / 未过项

## 6. 批量主题

只换槽位（文案、授权包装、本课插画），**不重开一套半成品图标**。见 `style-pack-and-slots.md`。
