# 暖调扁平培训插画 v1（番茄红素课件主视觉风格基线）

锚点图：`assets/generated/couple.png`（唯一通过风格评审的存量资产）。

## 风格定义

- **色系**：暖色为主——番茄红、珊瑚红、橙、桃色、奶油色；阴影用同色系深色，不用灰黑。
- **画法**：平涂色块 + 单侧柔和阴影（cel shading），圆润造型，闭合干净轮廓；无描边或细深棕描边。
- **题材处理**：人物、医学示意、分子图标一律同一扁平语言；禁 3D 光面 / 黏土质 / 照片写实 / 日系 Q 版 / 灰调素描。
- **构图**：单件主体居中，四周留边，主体不裁切。
- **禁出现**：任何文字/字母/数字、水印、背景道具、投影、辉光/雾光晕。

## 工艺约束（white-key 通路）

- 生图背景必须纯白 `#FFFFFF`（Gemini 不出透明底，靠 `scripts/whitekey-cutout.py` 抠图）。
- 主体内部允许白色（如毛巾、杯沿），靠贴边连通域保护，但主体外缘避免大面积纯白贴边。
- 交付尺寸 = `src/layout.ts` ASSET_SIZES 烘焙值，contain 适配居中，不重排版式。

## 质检门禁

`scripts/check-alpha.py`：四角 8×8 alpha ≤8（硬）；白晕环带 ≤15%；主体占比 25%–98%。
目检：丝绸底并排预览，对照本基线与锚点图。
