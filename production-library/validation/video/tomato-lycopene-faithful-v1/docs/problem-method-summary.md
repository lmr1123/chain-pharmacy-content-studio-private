# 商品复刻视频的问题与固定方法

> 2026-08-02 失败复盘：本版本自身违反了下列方法。它完成的是“参考启发下的新设计”，不是 100% 复刻。

## 本次根因

1. 把参考片压缩成“暖灰背景＋黄红标题＋几个章节”，没有逐页记录 TIME 开场、包装组、地图、实拍番茄、
   胶囊等量关系、原表格和总结页，导致一开始就选错版本。
2. 在逐帧合同建立前绑定通用模板和风格包，让模板反过来塑造参考，而不是由参考决定模板。
3. 缺少授权包装时没有建立同尺寸、同位置的包装坑位，擅自用番茄、器官和 AI 机制图替换。
4. 把质管修改直接写进观众画面和旁白，改变了参考内容；正确做法应是先复刻版本，再把合规疑点独立列出
   等业务／质管确认，或在指定位置用待确认占位。
5. 用“可编辑、高清、能导出、无黑帧”作为完成标准，却没有做参考与交付同一时刻左右对照。
6. 没有先签一个静态页和一个微镜头就直接批量生成，使错误框架被扩散到 MP4、网页和 PPTX 三端。

## 容易重复的问题

1. 把参考成片没有的业务新章节也称为“100%参考复刻”。
2. 只对齐章节和时码，却没有测字体、主视觉占屏、元素起中末动作和透明边缘。
3. 直接放大 480p 视频或从视频裁包装，导致模糊、水印、授权不清和后续无法替换。
4. 为 MP4、网页、PPTX 各写一套文案和位置，业务改一处却要返工三次。
5. “可编辑”只是底层参数可改，业务在网页上却不能直接点选、拖动、替图和改文字。
6. 忠实复刻时把草稿中的“最好、见效快、预防反复、美白抗皱更有效”也原样带入，忽略了同份输入里的质管要求。
7. 克隆音色听起来相似就直接进入成片，没发现参考提示尾句被重复带入每个语音分段。
8. 默认认为每台机器的 FFmpeg 都有 `subtitles`/`drawtext`，到最后编码才发现缺少 libass/freetype。
9. 只看导出接口返回，不对最终文件做 `ffprobe`、完整解码和抽帧；中途退出留下的残缺 MP4 容易被误认为成功。

## 固定方法

1. 先建逐镜合同，每个镜头显式标记参考观察、测量值、实现推断、业务新增和授权依赖。
2. 开始实现前锁定唯一 `template_id` 和 `style_pack_id`，参考完整成片仍是视觉和时间轴权威。
3. 参考像素不进入生产资产；人物、医学图和植物素材高清重建，文字保持独立层，包装和 Logo 保留业务授权槽位。
4. 只维护一份 Scene JSON，文字、图片、时长和布局使用稳定 ID；视频、网页和 PPTX 使用不同适配器读取同一数据。
5. 网页的可编辑性用真实操作验收：选中图片、替换素材、改文字、拖动／缩放、撤销／重做，并从当前快照导出 MP4/PPTX。
6. 参考段做同时刻对照；新增段只验收同风格、同字号、同动效语法和同字幕基线，不伪造“参考一致”证据。
7. 质管要求与业务草稿冲突时，保留原文和替换文案的可追溯清单；正式成片使用中性表述，包装功能和适宜人群等待实物资料确认。
8. 克隆语音实行双 ASR 门禁：首次定位参考文本泄漏／重复前缀，清理后再次转写确认；同时检查分段语速、总时长、响度与 True Peak。
9. 编码前先探测字幕滤镜；缺失时由网页生成逐句透明 PNG，再合成为一条透明字幕视频轨，最终只做一次 overlay。
10. 导出验收以文件为准：`ffprobe` 检查编码、分辨率、帧率、音频与时长，完整解码检查损坏，接触表和关键帧检查字幕、黑帧与画面顺序。
