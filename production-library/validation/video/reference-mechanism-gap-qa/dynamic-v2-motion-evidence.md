# 28–45 秒医学人体局部动态差分

对最终成片抽帧后，仅比较医学主体/机制面板区域。SSIM 小于 1 表示两个时刻并非相同静帧。

| 动态区域 | 比较时刻 | 裁切区域 | SSIM |
| --- | --- | --- | ---: |
| 全身人体、扫描线与风热聚拢 | 2.20s / 4.00s | `500×850 @ (440,70)` | 0.939708 |
| 肺部呼吸、红光与紫蓝体积邪气 | 10.20s / 10.90s | `1100×700 @ (700,140)` | 0.979781 |
| 咽喉红光聚焦 | 12.10s / 12.60s | `1100×700 @ (700,140)` | 0.998065 |
| 喉部红光与气流路径 | 13.10s / 14.00s | `1100×700 @ (700,140)` | 0.984879 |

验证命令使用 FFmpeg `crop` 与 `ssim` 滤镜；四项均检测到连续帧变化。咽喉段只改变局部光晕，因此整体裁切区 SSIM 接近但不等于 1。
