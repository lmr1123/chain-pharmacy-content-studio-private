# 关键页穿插规则 · 方案 C 数字人节奏

**锁定：** 2026-08-08  
**目的：** 让整课像「真人培训师穿插出现讲解」，而不是只有第 1 个内容页有人、后面全是静片。  
**配套：** `PRODUCT-MODE-presenter-scheme-C.md`（双布局 / 非关键页无人）

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| 真人感 | 数字人在课中**反复出现**（开场建立信任 → 中段强化决策 → 收尾关怀） |
| 控成本 | 动态数字人合计约 **1～3 分钟**，非整课全程动口型 |
| 不怪异 | 非关键页 = **全宽课件 + 旁白**，**不**放静帧站人 |
| 可复用 | 规则按「课型结构」标页，不绑死某一页号 |

---

## 2. 页角色分类

| 角色 | 布局 | 人 | 旁白 |
|------|------|----|------|
| **品牌壳**（封面/目录/尾页/竖版总结） | 全幅 | 无 | 可短可无（开场可一句） |
| **关键页 key** | 讲解安全版（收窄） | **动态数字人** | **必有**（驱动口型） |
| **非关键页** | 全宽金样（内容放大） | **无** | **必有**（讲解仍在继续） |

> 旁白是全课的；数字人是关键页的「出镜」。  
> **没有数字人 ≠ 没有声音。**  
> **声音全局一致：** 关键页口型轨与非关键页旁白必须同一 voice pack（`reference-pharmacist-qwen-v1`），见 `PRODUCT-MODE-presenter-scheme-C.md` §3。

## 3. 关键页选取规则（可执行）

### 3.1 数量

| 课篇幅 | 建议关键页数 | 动态时长预算（合计） |
|--------|--------------|----------------------|
| ≤10 页 | **2** | ~1–1.5 min |
| 11–20 页 | **3**（默认） | ~1.5–3 min |
| 21+ 页 | **3～4** | ≤3 min 优先砍单页时长 |

本课（18 页）→ **3 个关键页**。

### 3.2 位置模式：「头 – 腰 – 尾」锚点

```text
[封面][目录] → 【关键① 开场知识】 → 全宽讲解×N
              → 【关键② 中段决策】 → 全宽讲解×N
              → 【关键③ 收尾关怀】 → [尾页]
```

| 锚点 | 选什么页 | 作用 |
|------|----------|------|
| **① 开场知识** | 目录后**第一个**核心知识节（定义/疾病概览/机制） | 建立药师 IP + 听课状态 |
| **② 中段决策** | 全课**信息/动作密度最高**的一节（用药表/流程/禁忌） | 像真人在关键处站出来强调 |
| **③ 收尾关怀** | **专业关怀 / 总结行动** 类节（非纯表格尾页） | 收束、记忆点、服务话术 |

### 3.3 硬约束

1. **不选**封面、目录、纯品牌尾页、手机竖版一页通（布局不适配侧讲）。  
2. **相邻两个关键页之间**至少隔 **2** 个非关键页（避免连续动人像短视频）。  
3. 关键页之间**穿插全宽页**，保证「出镜 → 课件放大讲解 → 再出镜」节奏。  
4. 单关键页动态时长建议 **20～40s**（本 POC 样片约 12s 可先验收节奏）。  
5. 关键页清单写入 `key_pages.json`，**改页号只改配置不改代码逻辑**。

### 3.4 本课默认清单（急性上呼 18 页）

| 关键页 | 页号 | 节 | 理由 |
|--------|------|-----|------|
| ① | **3** | 疾病概览 | 目录后首个知识节，建立认知 |
| ② | **9** | 治疗用药（对症表/主药区） | 中段用药决策高峰 |
| ③ | **15** | 专业关怀 | 收尾关怀与行动建议 |

非关键页示例（**要有旁白、全宽无人**）：4 临床表现、5 检查、6–8 治疗展开、10–14 注意与关怀展开等。

## 4. 业务验收最小片（本轮交付）

不新生成多段 HeyGen 时，用 **1 段已签样动态人** 在 3 个关键位**复用示意节奏**；口型仅第 3 页与旁白严格对齐，②③ 标「节奏示意·待按本页旁白重渲」。

| 段 | 页 | 模式 | 验收点 |
|----|-----|------|--------|
| 壳 | 1–2 | 全宽短 hold | 开场干净 |
| 关键① | 3 | 动态数字人（真） | 侧讲+口型 |
| 非关键+旁白 | **4** | 全宽 + **新旁白** | 无人页也有讲解声 |
| 关键② | 9 | 动态复用 + 角标 | 中段再出镜 |
| 非关键+旁白 | **10** | 全宽 + **新旁白** | 第二段无人旁白 |
| 关键③ | 15 | 动态复用 + 角标 | 收尾再出镜 |
| 壳 | 18 | 全宽短 hold | 尾页 |

正式量产：②③ 按各页旁白各跑 HeyGen + v6.2 合成（仍遵守 1–3 min 总预算）。
