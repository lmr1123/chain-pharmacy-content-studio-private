## 3. 制作链路（验证期）

```text
金样 PPT 页导出静帧
  → 本机 TTS 按 script.md 出 narration.wav
  → HeyGen：人像 + 音频 → 数字人轨（透明/绿幕/白底均可）
  → 本地合成：左 slide + 右 avatar + 可选字幕
  → 永远先 15s 样片 → 确认 → 再全页
```

### 构图原则（已对齐参考 + 用户澄清）

```text
┌──────────────────────── 全屏 = 一张 PPT ────────────────────────┐
│  页眉 / 背景 / 页脚 贯通整页（不是左一块右一块）                    │
│  ┌── 页内内容栏（有意收窄）──┐  ┌── 同页右侧留白 ──┐              │
│  │ 标题·正文·图·表            │  │ （站人用）        │              │
│  └──────────────────────────┘  │    👤 叠在页前    │              │
│                                 └──────────────────┘              │
└───────────────────────────────────────────────────────────────────┘
```

| 是 | 否 |
|----|----|
| 全屏播放的就是 PPT | 左半 PPT 窗 + 右半独立人像区（分屏） |
| 页内排版把内容宽度收窄 | 后期把整页等比缩小腾空 |
| 人站在 PPT **前面** | 人与 PPT 左右硬分割 |
| 右侧留白是母版/版式的一部分 | 合成时硬裁两块拼 |

| 参数 | 值 |
|------|-----|
| 成片 | 1920×1080 · 30fps · H.264/AAC |
| PPT | 全幅一页铺底 |
| 内容栏 | 页内 max 宽约到 x≈1180（@1920），字号按培训可读，在栏内换行 |
| 站位 | 同页右侧留白；数字人叠层；尽量不压内容栏 |
| 错误 A | 内容仍全宽排 + 人盖上 → 挡字 |
| 错误 B | 整页缩成左小窗 + 右空场站人 → 分屏感 |

#### PPT 侧要改什么

1. 金样衍生 **`presenter` 变体母版**（不覆盖全宽 settled 下发版）。  
2. 同一套视觉 token；仅 **内容容器变窄**，右侧留白留给讲解人。  
3. 导出静帧后叠 HeyGen；业务纯 PPT 仍用全宽金样。

静态示意：

- **主推（正确）：** `outputs/layout-mock-correct-v2.png`  
  - 页内重排内容栏收窄 + 人像**去底**叠页前  
  - 抠图资产：`inputs/portrait-pharmacist-ip-cutout.png`  
- 带说明：`outputs/layout-mock-correct-v2-annotated.png`  
- 错误对照：人有白底挡 PPT → 旧 `layout-mock-fullppt-content-narrow.png`  
- 错误对照：未真收窄、直接盖人 → `layout-mock-ref-ratio.png`

### 用户两点质疑 → 结论（必须这样做）

| 问题 | 结论 |
|------|------|
| 人物有背景色挡 PPT | **必须去底/绿幕/抠像**，只保留人；色块底会盖住同页内容与背景 |
| 原金样全宽排版，没预留站位 | **必须做 presenter 变体**：页内内容宽度收窄、右侧同页留白；**不是**后期缩小整页，也不是左右分屏 |

生产清单：

1. PPT 母版/生成器：`presenter` 变体（内容栏 max≈58–62% 宽）  
2. 人像：白底证件照 → 抠图透明；HeyGen 导出尽量透明/绿幕再扣  
3. 合成：全幅 PPT 底 + 透明人叠右侧留白区

## 4. 手势与「指向课件」

参考真人片：站立、双手自然、可指向左侧屏幕。

| 阶段 | 做法 | 预期 |
|------|------|------|
| **P0 验证（当前）** | 现有半身照 → HeyGen 口型 + 微表情/头部 | 验证 IP 信任感与侧讲构图；**手势弱或无** |
| **P1 增强** | 补拍/补图：站立、双手可见、身体略侧向左侧课件；或 HeyGen Photo Avatar / 多姿态 | 自然抬手、指向左侧 |
| **不做** | 用当前「托腮抱臂」单张硬抠成「伸手指课件」 | 易假、易穿帮 |

**结论：** 前期样片以「侧讲 + 口型」过审；指向手势作为 P1，需要更合适的站姿素材。
