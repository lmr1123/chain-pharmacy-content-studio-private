## 课程结构

### 第一章 · 认识产品

#### S01 产品登场

**核心问题：** 这是什么产品？

**审核信息**

- 可可康灵芝胶囊；
- OTC、60 粒／瓶等包装可见信息以授权高清包装为准。

**画面与动作**

1. 深绿色背景中，一株赤灵芝由菌盖局部特写生长进入；
2. 镜头沿灵芝纹理推进，产品包装从光影中出现；
3. 标题“可可康灵芝胶囊”落位，右上保留大参林内部培训标识；
4. 镜头继续向包装中的灵芝图形推进，转入成分章节。

**屏显短文案**

- 可可康灵芝胶囊
- 商品知识培训
- 从灵芝、成分、功效到产品特点

**来源**：`refs/04-产品卖点.png`

#### S02 从灵芝认识两类核心成分

**核心问题：** 产品的知识基础是什么？

**审核信息**

- 灵芝多糖；
- 灵芝三萜。

**画面与动作**

1. 灵芝／孢子主体悬浮在中央；
2. 一束绿色粒子从主体左侧聚合成“灵芝多糖”；
3. 一束金色环形结构从主体右侧聚合成“灵芝三萜”；
4. 两条路径分别进入 S03、S04，不做一页左右栏机械朗读。

**屏显短文案**

- 两类核心有效成分
- 灵芝多糖
- 灵芝三萜

**来源**：`refs/01-认识灵芝-多糖三萜.png`

#### S03 灵芝多糖

**核心问题：** 公司课件如何描述灵芝多糖？

**审核信息**

- 增强免疫系统机能；
- 降低血压、预防心血管疾病的产生。

**画面与动作**

1. 多糖粒子在人体周围形成防护层；
2. 免疫细胞图形依次被点亮；
3. 血流路径平稳通过，出现课件第二项短文案；
4. 所有医学表述保持审核原文，不补充剂量或治疗结论。

**屏显短文案**

- 灵芝多糖
- 增强免疫系统机能
- 降低血压、预防心血管疾病的产生

**来源**：`refs/01-认识灵芝-多糖三萜.png`

#### S04 灵芝三萜

**核心问题：** 公司课件如何描述灵芝三萜？

**审核信息**

- 抗炎、镇痛、镇静、抗衰老、抑制肿瘤细胞；
- 促进淋巴细胞增殖；
- 提高巨噬细胞、NK 细胞、T 细胞的吞噬能力和杀伤力。

**画面与动作**

1. 三萜环形结构向外扩散镇静波纹；
2. 炎症红光逐渐减弱；
3. 淋巴细胞、巨噬细胞、NK 细胞、T 细胞依次点亮；
4. 屏幕只保留短关键词，详细内容由旁白分语义块讲解。

**屏显短文案**

- 灵芝三萜
- 镇静 · 抗炎 · 抗衰老
- 促进相关免疫细胞能力

**来源**：`refs/01-认识灵芝-多糖三萜.png`

#### S05 灵芝五方面作用图谱

**核心问题：** 灵芝作用如何形成整体认识？

**审核信息**

1. 增强与调节免疫力；
2. 抗氧化与延缓衰老；
3. 辅助保护肝脏；
4. 改善睡眠质量与缓解神经衰弱；
5. 辅助抗肿瘤。

**画面与动作**

1. 灵芝主体位于中心；
2. 免疫、抗氧化、肝脏、睡眠、课件列明的辅助抗肿瘤五个节点沿轨道逐一建立；
3. 每个节点只在成为讲解焦点时放大，其余退到背景；
4. 五节点完成后回收成一张完整知识图谱，作为第一章小结。

**来源**：`refs/02-认识灵芝-作用.png`

### 第二章 · 三大核心功效与症状演绎

#### S06 宁心安神助睡眠

**不是人物展示，而是连续状态演绎**

**审核信息**

- 宁心安神助睡眠；
- 多糖调节神经递质的含量和分泌；
- 三萜具有镇静、助眠作用。

**症状演绎**

1. **入睡困难：** 青年人物在床上翻身，时钟从 23:30 推进到 01:10；
2. **夜间易醒：** 房间由暗到亮闪过两次，人物睁眼看向时钟；
3. **日间疲倦：** 次日工作时注意力下降、眼下疲态出现；
4. **知识解释：** 多糖粒子和三萜镇静波纹分别进入，夜间呼吸节奏逐渐平稳；
5. 产品与“宁心安神助睡眠”结论出现。

**屏显短文案**

- 入睡困难
- 夜间易醒
- 日间疲倦
- 宁心安神助睡眠

**来源**：`refs/03-功效及适应人群.png`

#### S07 保肝护肝抗衰老

**审核信息**

- 保肝护肝抗衰老；
- 多糖和三萜减轻肝功能损伤并增强肝的解毒作用。

**症状／状态演绎**

1. **饮酒情境：** 中年人物在应酬场景中，酒杯数量与时间逐步累积；
2. **肝脏负担：** 画面转入体内，肝脏周围出现负担红光与积压粒子；
3. **作用解释：** 多糖、三萜两条路径进入，肝脏外形成保护层，积压粒子减少；
4. 产品与“保肝护肝抗衰老”结论出现。

**屏显短文案**

- 常喝酒伤肝／肝功能差
- 减轻肝功能损伤
- 增强肝的解毒作用
- 保肝护肝抗衰老

**来源**：`refs/03-功效及适应人群.png`

#### S08 提升免疫少生病

**审核信息**

- 提升免疫少生病；
- 三萜促进淋巴细胞增殖；
- 提高相关免疫细胞吞噬能力和杀伤力。

**症状／状态演绎**

1. **季节刺激：** 老年人物从暖室走入冷风，环境温度与气流发生变化；
2. **反复不适：** 打喷嚏、擦鼻、疲倦等状态依次出现，不使用疾病诊断词；
3. **免疫变化：** 免疫盾牌最初有缺口，淋巴细胞与相关免疫细胞逐一加入；
4. 盾牌闭合，产品与“提升免疫少生病”结论出现。

**屏显短文案**

- 免疫力低下
- 促进淋巴细胞增殖
- 提升相关免疫细胞能力
- 提升免疫少生病

**来源**：`refs/03-功效及适应人群.png`

#### S09 适应人群复盘

**核心问题：** 哪些具体情况与产品知识对应？

**画面与动作**

1. 不是三个人站立排队；
2. 横向快速回放三段生活切片：夜间失眠、饮酒伤肝、季节变化下反复不适；
3. 每段最后定格 1 秒，分别出现课件确认的人群名称；
4. 三条路径回到三大核心功效，建立“情况—功效”知识对应。

**屏显短文案**

- 经常失眠人群
- 常喝酒伤肝／肝功能差人群
- 免疫力低下人群

**限制**

青年、中年、老年只作为生活阶段演绎，不写成新增医学适用年龄。

**来源**：`refs/03-功效及适应人群.png`、`refs/09-总结.png`

### 第三章 · 三项产品特点

#### S10 优质产地，含量高

**必须完整呈现**

**审核信息**

- 安徽大别山产区赤灵芝；
- 课件标明每 100g 含多糖 9.13g；
- 灵芝三萜含量高。

**画面与动作**

1. 航拍式镜头越过大别山山脉与云雾；
2. 镜头落到林下赤灵芝，灵芝由小到大生长；
3. 灵芝进入称量／检测视觉，数值从 0 滚动到 `9.13g/100g`；
4. 数值与“大别山赤灵芝”共同进入产品包装旁，形成第一项产品差异。

**屏显短文案**

- 优质产地，含量高
- 安徽大别山赤灵芝
- 每 100g 含多糖 9.13g
- 灵芝三萜含量高

**来源**：`refs/04-产品卖点.png`

#### S11 专利工艺，吸收好

**必须完整呈现**

**审核信息**

- 专利浓缩提取；
- 二次浓缩提取／双重提取；
- 胶囊剂型锁住营养，服用方便。

**画面与动作**

1. 赤灵芝切片进入第一次浓缩提取装置；
2. 第一次提取液流入第二段装置，画面明确出现“二次浓缩提取”；
3. 液体颜色与浓度视觉逐步加强，形成与普通一次处理的工艺差异；
4. 提取物进入胶囊成形，最后回到产品。

**屏显短文案**

- 专利工艺，吸收好
- 第一次浓缩提取
- 二次浓缩提取
- 胶囊剂型 · 服用方便

**内容边界**

只解释课件确认的“双重／二次浓缩提取”工艺差异，不自行增加吸收率、倍数、时间或实验数据。

**来源**：`refs/04-产品卖点.png`

#### S12 大品牌，值得信赖

**必须完整呈现**

**审核信息**

- 中山可可康生产；
- 通过国家 GMP 的工厂；
- 采用国内先进生产技术。

**画面与动作**

1. 中山可可康工厂／生产主体以授权材料进入；
2. 生产线、质量检查、封装三个环节连续推进；
3. GMP 标识以授权材料为准，盾牌与勾选动画建立质量信任；
4. 产品从生产线末端进入主视觉，完成三项产品特点章节。

**屏显短文案**

- 大品牌，值得信赖
- 中山可可康
- GMP
- 国内先进生产技术

**来源**：`refs/04-产品卖点.png`

#### S13 三项产品特点复盘

**画面与动作**

1. 大别山赤灵芝、二次浓缩提取、生产与 GMP 三段画面不是缩成静态插画卡；
2. 通过一条“原料—工艺—生产”的流动路径连接；
3. 产品包装位于路径末端；
4. 每个节点保留一个核心证据：`9.13g/100g`、`二次浓缩提取`、`中山可可康／GMP`。

**屏显短文案**

- 原料：大别山赤灵芝
- 工艺：二次浓缩提取
- 生产：中山可可康 · GMP

### 第四章 · 联合应用与服用周期

#### S14 三套联合应用

**内容原则**

只讲公司课件确认的组合方案与作用逻辑，不讲销售话术。

**三个连续短镜头**

1. 失眠方向：谷维素片＋灵芝胶囊 → 营养神经＋镇静助眠；
2. 肝功能异常方向：护肝片＋灵芝胶囊 → 疏肝降酶＋保肝解毒；
3. 免疫力低下方向：转移因子口服溶液＋灵芝胶囊 → 调节免疫＋提升相关免疫细胞能力。

每段先回放对应状态 1 秒，再进入两款授权包装与作用路径；没有顾客、问诊和成交动作。

**来源**：`refs/05-联合用药-失眠护肝.png`、`refs/06-联合用药-免疫.png`

#### S15 建议服用周期

**审核信息**

- 1 个月为 1 个服用周期；
- 建议连续服用 2～3 个月。

**画面与动作**

1. 月历进入；
2. 第一个月被绿色环完整圈出；
3. 时间轴继续推进到第二、第三个月；
4. 不加入课件未提供的剂量与频次。

**来源**：`refs/09-总结.png`

### 第五章 · 商品知识总结

#### S16 从六个维度真正认识产品

**回收维度**

1. 两类核心有效成分；
2. 灵芝五方面作用；
3. 三大核心功效；
4. 三类适应人群；
5. 三项产品特点；
6. 联合应用与服用周期。

**画面与动作**

灵芝、多糖、三萜、三段症状演绎、原料—工艺—生产路径、联合应用与月历依次回收到产品
周围。最终只保留产品主视觉、课程标题和“内部培训资料”，不使用销售口诀收尾。

## 素材与授权缺口

- 可可康灵芝胶囊授权高清包装；
- 谷维素片、护肝片、转移因子口服溶液授权高清包装；
- 中山可可康工厂／生产线／GMP 授权材料；
- 产品数据与工艺表述的最终审核版本。

缺失时可以在设计稿保留可替换槽，但不得仿造品牌包装或认证证据。

## 设计稿签样标准

- 完整覆盖 16 场，不以 20 秒局部短样代替完整课程；
- 三项产品特点在可见设计中均有完整证据与动作；
- 三类适应人群均通过状态变化演绎，不是人物排队；
- 每场 2～4 个动作节点，只有一个主运动焦点；
- 文案全部可追溯到 `refs/01`～`06`、`refs/09`；
- `refs/07`～`08` 销售案例不进入主课。
