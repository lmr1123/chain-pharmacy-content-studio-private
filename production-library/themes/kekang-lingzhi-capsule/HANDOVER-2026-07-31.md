## 4. 版本演进（为何停在这里）

| 版本 | 做法 | 用户反馈 |
|------|------|----------|
| v1 | PPT 裁切 + 白底字卡堆砌 | 太差；不能截图当资产 |
| v2 | 设计生图 + 大卡弹入（偏 Q10 3D 医学风） | 插画风不好看；无数字人；念 PPT；字幕土 |
| v3 | 风热卡通风 + 药师数字人 + 口语 + 胶囊字幕 | 结构错：先讲成分；呆板切小图 |
| **v4** | 六段顺序 + 多版式 + 联合公式 A+B=功效 | **做得不好 → 暂停** |

### v4 已实现但仍被否定的可能原因（供重启时诊断，非定论）

- 整体仍偏「模板卡堆砌」，与风热证的 **信息密度 / 场景切换节奏 / 母版质感** 差距大。  
- 联合用药包装是 **代码示意卡**（「示意包装」），不像课件真实包装信息层级（虽不能直接用 PPT 像素）。  
- 数字人偏小、口型/姿态单一，讲解感弱。  
- 旁白与画面节拍、风热「一句一画面」的剪辑感仍不够。  
- 产品特点段可能出现滑入未完成就切走的空/半完成帧。  
- **未做**用户可签样的「静帧 × 分镜批准」闸门，直接连渲整片。

## 7. DO / DON'T（下一会话强制）

### DO

1. **先确认用户是否恢复本支线**；未确认只维护文档/资产，不自动开渲。  
2. 重启时优先：**静帧分镜批准 → 再旁白 → 再动效 → 再整片**（gold-sample-first）。  
3. 叙事严格 **睡眠切入 + 六段顺序**；功效/人群/联合 **只用 PPT 确认口径**。  
4. 插画锁定 **pharmacy-health-cartoon-v1**，用 `production-symptoms` 作风锚；图内无字、无真实包装仿造。  
5. 联合用药做 **公式版式**，包装用合规示意或授权包装槽，**不用 PPT 截图当成片像素**。  
6. 数字人复用 **dashenlin-presenter + MOUTH_RIG**；口型颜色从角色原图取（见 lessons 口型融合条）。  
7. 动效对标风热：**多布局、stagger、滑入、信息板**，避免「全片一种三卡切换」。  
8. 旁白：口语短句 + `v5-smooth` 整段连读；禁止超 1.18× 暴力加速。  
9. 改完后更新 `review-hub` 的可可康 Tab 与本 HANDOVER 状态。  
10. 被纠正后写 `tasks/lessons.md`。

### DON'T

1. **不要**在未获用户同意时继续迭代 v4「再改一刀」。  
2. **不要**用 `public/kekang-lingzhi/` 根目录旧 PPT 裁切图。  
3. **不要**开场讲多糖/三萜当主叙事（可作后置知识点，用户未要求则先别加）。  
4. **不要**把 script-draft-v1 的「健脾/扶正」当功效（已被 PPT 三大功效覆盖）。  
5. **不要**自编联合方案或药名组合。  
6. **不要**把风热深色科技壳直接套到商品浅蓝培训片而不改信息层级。  
7. **不要**字幕回到粗描边大黄字（除非用户明确要求对齐某参考片）。  
8. **不要**跳过静帧审批直接长片连渲后要求用户「整体感受一下」。  
9. **不要**假设 v4 mp4 可对外或可当金样。
