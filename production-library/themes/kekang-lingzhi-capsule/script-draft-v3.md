## 2. 灵芝的作用（五点 · 对齐课件）

### 【旁白 / 上屏原文】

**灵芝的作用：**

1. **增强与调节免疫力：** 灵芝多糖和肽聚糖等成分被认为能激活巨噬细胞、自然杀伤细胞（NK细胞）、T淋巴细胞、B淋巴细胞等多种免疫细胞，促进细胞因子（如干扰素、白介素）的产生。  
2. **抗氧化与延缓衰老：** 灵芝富含多糖、三萜类、多酚等强效抗氧化剂。  
3. **辅助保护肝脏：** 辅助减轻化学性肝损伤（如长期饮酒、接触环境毒素、某些药物带来的负担），促进肝细胞修复，帮助维持正常的肝功能指标（如转氨酶水平）。  
4. **改善睡眠质量与缓解神经衰弱：** 对于入睡困难、睡眠浅、多梦、早醒等睡眠障碍人群，可帮助改善睡眠质量，延长深度睡眠时间。也可能帮助缓解焦虑、紧张情绪和精神疲劳（神经衰弱症状），使人感觉更平静、精力更充沛。  
5. **辅助抗肿瘤：** 具有抑制肿瘤细胞增殖、促进肿瘤细胞凋亡、抑制肿瘤血管生成、增强放化疗效果或减轻其副作用的作用。

## 3. 产品功效及适应人群

### 【标题】二 产品功效及适应人群

### 三大核心功效（原文）

**① 宁心安神助睡眠**  
灵芝胶囊含有多糖和三萜，其中灵芝多糖可以通过调节神经递质的含量和分泌，而灵芝三萜，具有镇静、助眠作用；两者结合，改善失眠效果更佳。

**② 保肝护肝抗衰老**  
灵芝多糖和三萜，能减轻肝功能损伤并能增强肝的解毒作用，避免毒物在体内积压，从而达到保肝护肝抗衰老作用。

**③ 提升免疫少生病**  
灵芝三萜能促进淋巴细胞增殖，提高巨噬细胞、NK细胞、T细胞的吞噬能力和杀伤力，提高免疫力。

### 【联合用药旁白串讲 · 可连读】

联合用药，课件给出三套方案，请同事记牢场景和搭配。

第一，**失眠**：入睡困难、易醒、早醒。方案是 **谷维素片加灵芝胶囊**。谷维素营养神经、有助于入眠，但长期吃容易依赖；灵芝胶囊多糖调节神经递质，三萜镇静助眠，两者结合改善失眠效果更佳。

第二，**肝功能异常**：肝损伤、病毒性肝炎。方案是 **护肝片加灵芝胶囊**。护肝片疏肝理气、健脾消食、降低转氨酶；搭配灵芝胶囊减轻肝损伤、增强解毒，保肝护肝。

第三，**免疫力低下**：易反复生病、抵抗力差。方案是 **转移因子口服溶液加灵芝胶囊**。转移因子调节免疫、增加T细胞；灵芝三萜促进淋巴细胞增殖，提高吞噬与杀伤力，提高免疫力。

## 6. 优秀销售案例（课件原文 · 可选镜头）

### 案例 1 · 主题联合用药：气血康口服液 + 灵芝胶囊

- **顾客背景：** 顾客感觉自身气血虚弱，胃口差吃不下还睡不好。  
- **回顾：** 女性顾客进店买气血康口服液，沟通后了解到晚上经常睡不着、状态差、没胃口。在气血康基础上推荐搭配灵芝胶囊：可宁心安神，用于神经衰弱的失眠健忘，还有健脾和胃，与症状匹配。顾客百度后认可，拿了 4 盒。  
- **点评：** 细问顾客情况 + 专业解说功效 + 适合方案推荐。

### 案例 2 · 阳江营运区 01895 店刘仕开

- **顾客背景：** 顾客进店买胃药，问诊后推荐灵芝胶囊。  
- **回顾：** 长期消化不良，常买健胃消食片、多潘立酮片，免疫力也差。分析：胃药可缓解胀气促进消化，但肠胃弱、体质差还要从根上调，建议搭配灵芝胶囊——**不仅能健脾和胃还能增强免疫力**，像“修车的同时还要保养发动机”。叮嘱少吃辣的冰的，多吃小米粥、山药。复购两盒。  
- **点评：** 耐心服务顾客 + 专业推荐 + 贴心叮嘱。
