# 疾病科普插画 Style Brief · pharmacy-health-cartoon-v1

与 `assets/component-library/symptoms/symptoms-v1-generation-recipes.md` 对齐。

## 画风

- 友好扁平 2D 中国药店培训卡通
- 中深棕线稿、圆润简化解剖、赛璐璐平涂、克制软阴影
- 方图 1:1，约 10% 安全边距；缩略可读 ≥150px
- **图内无文字、无药名剂量、无真实包装仿造、无水印**

## 生图公共前缀（中英可混，以英文约束画风更稳时用英文）

```text
Use case: scientific-educational pharmacy training
Style: friendly flat 2D Chinese pharmacy-training cartoon; medium dark-brown outline;
rounded simplified anatomy; flat cel colors; restrained soft shading;
same patient system as pharmacy-health-cartoon-v1.
Composition: square 1:1; centered subject; 10% safe margin; transparent or solid soft pastel bg.
Constraints: original artwork; no text; no logo; no watermark; no photorealism; no 3D; no horror.
```

## 主题扩展

- 先查 series 成员能否表达；不能再按本 brief 新生图入 candidates → 过目 → master
- 草药：植物写实清洁插画（botanical-clean），白底抠透明
- 机理层：外感病族可复用 human-body + wind-heat-dynamic 骨架，须过目

## 过目标准

1. 语义一眼可读（不看 label 也大致懂）
2. 与同片其他症状图人物/线宽一致
3. 透明底四角干净（贴丝绸/深蓝底不穿帮）
4. 未通过不得写入 theme `assets/` 的 approved 清单
