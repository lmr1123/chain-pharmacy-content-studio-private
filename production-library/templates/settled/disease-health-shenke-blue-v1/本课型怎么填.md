# 本课型怎么填 · 疾病健康知识培训 PPT（参课蓝）

- 产物：可编辑 PPTX
- 空白 Word：同目录 `业务提交_空白模板.docx`
- 填写参考：`../../03_填写参考/disease-health-shenke-blue-v1/业务提交_填写参考.docx`（仅学格式）

## 推荐板块（可删可增）

1. 疾病概览（定义 + 病因）
2. 临床表现
3. 检查方法
4. 治疗用药（一般 / 全身 / 局部 / 对症表）
5. 用药注意事项（禁用须审核稿）
6. 专业关怀
7. 一页通（竖版，可选）

## 填写要点

- 业务只写自然板块正文与授权图，不写页码/坐标。
- 对症表可标重点药名；包装用授权原图，禁止伪造品牌包装。
- 注意事项：仅「禁用」类表述在成品中标红；医学结论须业务/医学复核。
- 先收「内容初稿 + 缺口清单」，确认后再出 PPTX。

- 对症表/注意事项列表：有几条写几条；没有的板块整节删除。
