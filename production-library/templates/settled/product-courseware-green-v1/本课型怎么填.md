# 本课型怎么填 · 绿色单品 PPT（如金银花露）

- 产物：可编辑 PPTX
- 空白 Word：同目录 `业务提交_空白模板.docx`
- 填写参考：`../../03_填写参考/product-courseware-green-v1/业务提交_填写参考.docx`（仅学格式）

## 推荐板块（可删可增）

1. 商品介绍（成分/功能/用法）
2. 核心卖点（1～N 条）
3. 适宜人群（1～N 类）
4. 联合用药话术（1～N 组；2 组就 2 行）
5. 品种对标（可选，无则整节删）
6. 注意事项（可选）

## 填写要点

- 用空白通用 Word，按上列板块起标题即可；不必写页码。
- 联合用药只写真实有的组数，禁止为对齐示例空出第三行。
- 先收「内容初稿 + 缺口清单」，确认后再出 PPTX。

## 对话示例（复制给 WorkBuddy）

```
我要用【绿色单品 PPT（如金银花露）】，主题是【病名或商品名】。
请按金样结构整理内容初稿与素材计划后生成成片。
```

## 图片怎么来（重要）

- **业务提供：** 本品 / 搭档 / 竞品授权包装图
- **WorkBuddy 按《素材计划》生成：** 注意事项等知识插图
- **禁止：** 打开金银花金样 PPT 改字交付；禁止沿用金样像素
- 内容确认后生图；`approve visual --asset-bindings` 绑定本主题新图后才能出片

## 列表 / 模块硬规则

- 有几条写几条；联合用药 2 组 → 成品 2 行
- 禁止空行凑满金样示例数
- 没有的板块整节删除
