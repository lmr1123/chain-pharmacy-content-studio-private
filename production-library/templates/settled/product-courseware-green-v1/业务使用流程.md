# 绿色商品培训课件 · 业务使用流程

> 适用模板：`template.product-courseware-dashenlin-green-v1`（大参林绿 · 金银花露母版）  
> 产物：可编辑 PPTX 商品培训课件（内部学习）  
> 状态：active 固定课型。此前“绿色五页下线”的状态已被 2026-08-09 业务验收决定取代。
> 原则：**先定模板与内容，再出 PPT**；资料可以不完整地启动，但正式稿必须补齐审核内容、授权真图和视觉确认。

---

## 业务完整工作流（标准）

```
① 选模板 → ② 交资料（可残缺） → ③ 审初稿/缺口 → ④ 补图并验代表图
→ ⑤ 内容/商品图/视觉确认 → ⑥ 正式 PPTX → ⑦ 逐页 QA 后交付
```

### 第 1 步｜先选模板

业务或协作方先明确要用哪一类课件模板，例如：

| 模板 | 典型页型 | 适合 |
|------|----------|------|
| **绿色商品培训**（本模板） | 封面 / 商品介绍·卖点·人群 / 联合用药(推荐) / 品种对标 / 注意事项 | 单品店员培训、联合推荐、对标话术 |

**未选定模板前，不进入成片排版。**  
本模板锁定五页绿色框架；业务只交自然语言/Word 和素材，**不**按内部页码、JSON、CLI、卡片坐标逐栏填空。

---

### 第 2 步｜提交资料（允许不完整）

可以只给 **一个商品名**，也可以给说明书、话术、竞品、包装图等任意组合。

| 资料类型 | 是否必须 | 说明 |
|----------|----------|------|
| 商品名称 | **建议有** | 仅此一项也可启动初稿 |
| 规格 / 编码 / 零售价 | 可选 | 没有则标「待确认」 |
| 成分、功能/定位、用法 | 正式稿必须审核 | 只取业务提供的标签、说明书或审核稿；WorkBuddy 不自行编医学功效/剂量 |
| 核心卖点、适宜人群 | 正式稿必须审核 | 可先列缺口，不用品类常识冒充已审结论 |
| 联合用药 / 联合推荐 | 可选 | **有几条写几条**，不强行凑满 3 条 |
| 竞品对标 | 可选 | 无竞品则表内标「待确认」 |
| 注意事项 | 可选 | 保健品/药品口径不同，须业务审 |
| 包装图、Logo、证据图 | **正式稿必须** | 业务提供授权真图；不得 AI 仿造包装或证据 |
| 搭档包装图 | 有联合推荐时必须 | 每个搭档使用业务授权真图 |
| 注意事项等非商品插图 | WorkBuddy 负责 | 按固定图槽生成/绑定，不让业务写提示词或找普通配图 |

**业务不必：**

- 按 PPT 页码填表  
- 指定字号、坐标、组件 ID  
- 为对齐旧样而硬写空行/空卡  

**业务只需：** 说清楚「这个商品要培训什么」+ 手头有什么资料。

---

### 第 3 步｜生成并确认「初稿」（文字稿 / 内容规划）

制作侧（AI 或内容同学）根据模板 + 资料输出 **可审阅的内容初稿**，至少包括：

1. 建议章节与顺序（对应页型）  
2. 每页正文、要点、表格行（行数随内容变）  
3. 待确认项清单（价格、编码、竞品、合规表述等）  
4. 素材缺口（包装图、示例插图等）  

**默认规则：**

- **内容优先**：联合推荐 2 条就 2 行，不硬凑 3 行  
- **布局随内容**：表列、合并单元格、字号由制作侧适配  
- **未确认功效/价格/竞品**：只进入缺口清单，不进入正式稿，不编造业务未给的结论或数字

**业务在这一步只做一件事：改内容、点确认。**  
确认前 **不生成正式 PPT**（可先出规划稿，避免反复改版式）。

确认话术示例：

- 「初稿可以，按这个出 PPT」  
- 「初稿第 2 节改成……，其他 OK，再出 PPT」  

---

### 第 4～7 步｜补素材、三道确认、生成与 QA

初稿通过后，WorkBuddy：

1. 收齐并绑定业务授权的包装图、Logo、标签/证据；非商品插图由 WorkBuddy 按图槽生成或取已批准素材
2. 先把 1 张代表插图放进真实 PPT 图槽做比例、裁切、主体大小检查，通过后再补齐同系列插图
3. 依次记录 **内容确认、商品图确认、视觉确认**；任一内容或图片变更后重新确认
4. 三道确认齐全后套用本模板生成可编辑 PPTX（字体统一 **微软雅黑**）
5. 对五页逐页检查文字溢出、缺图、占位符、金样残留与可编辑性；QA 未通过不得进入交付区

业务拿到 PPT 后可自行小改版式；医学口径、商品图或主要话术有变化时，应回到初稿并重新确认后生成。

正式交付不得含「待确认」「包装图待接入」或示例图片。

## 给业务的最短口令

> 「我要用 **绿色商品培训 PPT（金银花固定课型）**，商品是 **×××**。资料如下（可很少）。请先出 **内容初稿、缺口和素材计划**；不要自行编医学内容，确认前不要出正式 PPT。」

---

## 给制作侧（AI）的执行约定

后续会话默认按本流程引导，不要跳步：

| 阶段 | 该做 | 不该做 |
|------|------|--------|
| 用户未选模板 | 先问/推荐模板 | 直接按某固定 18 页填空 |
| 只有商品名 | 基于母版结构起草初稿，标清模拟/待确认 | 假装资料齐全、直接出终稿 PPT |
| 初稿未确认 | 只改文字规划 | 反复生成完整 PPT 消耗轮次 |
| 初稿已确认 | 补真图/插图并走三道确认；通过后出 PPT + 逐页 QA | 带槽位/示例图发布正式稿；擅自加页、硬凑联合用药行数 |
| 联合用药/推荐 | 有几条排几条；本品图合并列 + 搭档图分行 | 只在中间行塞本品包装 |

**联合用药页版式约定（本母版已修正）：**

- 「联合商品图」：每一行各自一张搭档包装  
- 「本品图」：纵向合并，贯穿全部联合行，保证每行都与本品关联

## 本模板页型对照（绿色商品培训）

| 页 | 页型 | 内容来源 |
|----|------|----------|
| 封面 | 品名 + 专业力 | 商品名 |
| 01 | 商品介绍、核心卖点、适宜人群 | 标签/话术/口述 |
| 02 | 联合用药 / 联合推荐话术 | 场景 × 搭档 × 话术（行数可变） |
| 03 | 品种对标 | 本品 vs 竞品（可待确认） |
| 04 | 注意事项 | 说明书口径；示意插图可示例后替换 |

正式课型锁定上述 5 页框架；卡片/联合行只按已审核内容填充，不用空行凑金样数量。
