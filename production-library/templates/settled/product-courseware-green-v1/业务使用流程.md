# 绿色商品培训课件 · 业务使用流程

> 适用模板：`template.product-courseware-dashenlin-green-v1`（大参林绿 · 金银花露母版）  
> 产物：可编辑 PPTX 商品培训课件（内部学习）  
> 原则：**先定模板与内容，再出 PPT**；资料可以不完整，布局由内容驱动，不硬凑字段。

---

## 四步工作流（标准）

```
① 选模板  →  ② 交资料（可残缺）  →  ③ 审初稿  →  ④ 确认后出 PPT
```

### 第 1 步｜先选模板

业务或协作方先明确要用哪一类课件模板，例如：

| 模板 | 典型页型 | 适合 |
|------|----------|------|
| **绿色商品培训**（本模板） | 封面 / 商品介绍·卖点·人群 / 联合用药(推荐) / 品种对标 / 注意事项 | 单品店员培训、联合推荐、对标话术 |

**未选定模板前，不进入成片排版。**  
模板只决定风格与可选页型，**不**要求业务按固定页码、卡片数、字段表逐栏填空。

---

### 第 2 步｜提交资料（允许不完整）

可以只给 **一个商品名**，也可以给说明书、话术、竞品、包装图等任意组合。

| 资料类型 | 是否必须 | 说明 |
|----------|----------|------|
| 商品名称 | **建议有** | 仅此一项也可启动初稿 |
| 规格 / 编码 / 零售价 | 可选 | 没有则标「待确认」 |
| 成分、功能/定位、用法 | 可选 | 可从标签、旧课件、口述补 |
| 核心卖点、适宜人群 | 可选 | AI 可按品类常识起草，须业务审 |
| 联合用药 / 联合推荐 | 可选 | **有几条写几条**，不强行凑满 3 条 |
| 竞品对标 | 可选 | 无竞品则表内标「待确认」 |
| 注意事项 | 可选 | 保健品/药品口径不同，须业务审 |
| 包装图、搭档包装图 | 可选 | 无图则用「包装图待接入」槽位；注意事项等示意插图可由制作侧先出示例图供替换 |

**业务不必：**

- 按 PPT 页码填表  
- 指定字号、坐标、组件 ID  
- 为对齐旧样而硬写空行/空卡  

**业务只需：** 说清楚「这个商品要培训什么」+ 手头有什么资料。

---

### 第 3 步｜生成并确认「初稿」（文字稿 / 内容规划）

制作侧（AI 或内容同学）根据模板 + 资料输出 **可审阅的内容初稿**，至少包括：

1. 建议章节与顺序（对应页型）  
2. 每页正文、要点、表格行（行数随内容变）  
3. 待确认项清单（价格、编码、竞品、合规表述等）  
4. 素材缺口（包装图、示例插图等）  

**默认规则：**

- **内容优先**：联合推荐 2 条就 2 行，不硬凑 3 行  
- **布局随内容**：表列、合并单元格、字号由制作侧适配  
- **未确认功效/价格/竞品**：用「待确认」或弱化表述，不编造业务未给的关键数字（模拟演示需标明）  

**业务在这一步只做一件事：改内容、点确认。**  
确认前 **不生成正式 PPT**（可先出规划稿，避免反复改版式）。

确认话术示例：

- 「初稿可以，按这个出 PPT」  
- 「初稿第 2 节改成……，其他 OK，再出 PPT」  

---

### 第 4 步｜确认后生成 PPT

初稿通过后，制作侧：

1. 按已确认内容写入结构化稿（如 JSON）  
2. 套用本模板风格生成可编辑 PPTX  
3. 字体统一 **微软雅黑**（见项目字体规范）  
4. 缺图处用槽位或示例图（示例图可替换，须标注）  
5. 交付路径与 QA 预览页  

业务拿到 PPT 后可自行：

- 替换包装图 / 示例插图  
- 改少量文字  
- 补「待确认」字段  

大改内容建议 **回到第 3 步改初稿再出**，避免只在 PPT 里大改导致下次批量不一致。

---

## 给业务的最短口令

> 「我要用 **绿色商品培训模板**，商品是 **×××**。资料如下（可很少）。请先出 **内容初稿** 给我确认，确认后再出 **PPT**。」

---

## 给制作侧（AI）的执行约定

后续会话默认按本流程引导，不要跳步：

| 阶段 | 该做 | 不该做 |
|------|------|--------|
| 用户未选模板 | 先问/推荐模板 | 直接按某固定 18 页填空 |
| 只有商品名 | 基于母版结构起草初稿，标清模拟/待确认 | 假装资料齐全、直接出终稿 PPT |
| 初稿未确认 | 只改文字规划 | 反复生成完整 PPT 消耗轮次 |
| 初稿已确认 | 出 PPT + 槽位/示例图 | 擅自加页、硬凑联合用药行数 |
| 联合用药/推荐 | 有几条排几条；本品图合并列 + 搭档图分行 | 只在中间行塞本品包装 |

**联合用药页版式约定（本母版已修正）：**

- 「联合商品图」：每一行各自一张搭档包装  
- 「本品图」：纵向合并，贯穿全部联合行，保证每行都与本品关联

## 本模板页型对照（绿色商品培训）

| 页 | 页型 | 内容来源 |
|----|------|----------|
| 封面 | 品名 + 专业力 | 商品名 |
| 01 | 商品介绍、核心卖点、适宜人群 | 标签/话术/口述 |
| 02 | 联合用药 / 联合推荐话术 | 场景 × 搭档 × 话术（行数可变） |
| 03 | 品种对标 | 本品 vs 竞品（可待确认） |
| 04 | 注意事项 | 说明书口径；示意插图可示例后替换 |

页数与栏目可因内容增减，**不要求永远 5 页、永远 3 条联合**。
