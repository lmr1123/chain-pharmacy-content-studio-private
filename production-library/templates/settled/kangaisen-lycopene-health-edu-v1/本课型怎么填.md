# 本课型怎么填 · 番茄红素成分健康科普 PPT（米白番茄红）

- 产物：20 页可编辑 PPTX
- 空白 Word：同目录 `业务提交_空白模板.docx`
- 填写参考：`../../03_填写参考/kangaisen-lycopene-health-edu-v1/业务提交_填写参考.docx`（仅学格式）

## 推荐板块（可删可增）

1. 封面与六章目录
2. 定义、来源与影响因素
3. 结构、比较数据与原理
4. 审核发现与证据
5. 建议流程、使用边界与注意事项
6. 应用场景、总结与结束页

## 填写要点

- 这是 20 页成分健康科普课型，不是福尔商品课件4。
- 业务按自然页面填写；WorkBuddy 负责转换为内部 107 个文字槽和 69 个图片绑定，业务不编辑 JSON。
- 草稿会产出《素材计划》：全部图槽归系统生成（无单独包装图闸门）；内容确认后由 WorkBuddy 生图并 `--asset-bindings`。
- 原康爱森正文和番茄红素参考图只用于看框架；正式新主题全部换文案、换图并绑定内容与视觉审批。
- 涉及定义、机理、数据、功效、建议、风险或用法的内容必须来自业务审核稿，不得由 WorkBuddy 补写。

## 对话示例（复制给 WorkBuddy）

```
我要使用【番茄红素成分健康科普 PPT（米白番茄红）】。资料见 Word。
请先整理 20 页内容初稿、缺口清单和素材计划；在我确认内容与视觉之前，不要生成正式 PPTX。
```

## 图片怎么来（重要）

- **业务提供：** 审核口径与必要授权说明（本课型无单独 product_image 闸门）
- **WorkBuddy 按《素材计划》生成：** 全部 69 个页面/母版图槽
- **禁止：** 打开康爱森金样 PPT 改字交付；禁止沿用番茄红素参考图像素
- 内容确认后才会批量生图；`approve visual --asset-bindings` 绑定本主题新图后才能出片
