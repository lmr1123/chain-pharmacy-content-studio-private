# 本课型怎么填 · 疾病科普视频（如风热证）

- 产物：MP4 培训视频
- 空白 Word：同目录 `业务提交_空白模板.docx`
- 填写参考：`../../03_填写参考/health-video-reference-tech-v1/业务提交_填写参考.docx`（仅学格式）

## 推荐板块（可删可增）

1. 课程主题 / 开场
2. 典型症状
3. 病因与机理
4. 治疗思路
5. 用药与生活建议
6. 总结

## 填写要点

- 金样可用：`风热证_疾病科普视频_金样_v1.mp4`（对照）与 `…_可编辑金样_v2.mp4`（生产基线）。
- 每个自然板块 = 可直接讲解的审核正文；有几章写几章，不需要的整段删。
- 旁白必须是药师/合规已审表述；正式成片用模板 voice/ 克隆药师声，禁止系统朗读。
- 片尾 Logo 等授权图缺则记缺口，禁止假包装。

## 对话示例（复制给 WorkBuddy）

```
我要用【疾病科普视频】模板，主题是【病名】。
内容围绕：典型症状…、病因机理…、治疗与用药建议…。
请按金样整理后生成培训视频。
```

## 列表 / 模块硬规则

- 有几条写几条；联合用药 2 组 → 成品 2 行
- 禁止空行凑满金样示例数
- 没有的板块整节删除
