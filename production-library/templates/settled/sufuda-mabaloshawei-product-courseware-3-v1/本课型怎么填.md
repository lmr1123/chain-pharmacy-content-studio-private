# 本课型怎么填 · 商品培训课件3（可编辑 PPT，速福达标准课型）

- 产物：13 页可编辑 PPTX
- 空白 Word：同目录 `业务提交_空白模板.docx`
- 填写参考：`../../03_填写参考/sufuda-mabaloshawei-product-courseware-3-v1/业务提交_填写参考.docx`（仅学格式）

## 推荐板块（可删可增）

1. 课程开场 / 品类背景
2. 商品介绍与核心利益
3. 产品特点 / 证据
4. 适宜人群
5. 联合用药（有几组写几组）
6. 总结

## 填写要点

- Word 按 12 个主题内容单元写审核文案；适宜人群单元导出时拆为两页，因此终稿共 13 页。
- 草稿会产出《素材计划》：包装/Logo 归业务真图；约 23 槽主题插图由 WorkBuddy 在内容确认后生成并绑定。
- 当前新主题自助只交付 PPTX；MP4 仍在生产接入中，不承诺生成。

## 对话示例（复制给 WorkBuddy）

```
我要用【商品培训课件3（可编辑 PPT，速福达标准课型）】，主题是【病名或商品名】。
请按金样结构整理内容初稿与素材计划后生成成片。
```

## 图片怎么来（重要）

- **业务提供：** 本品包装（packGroup）、Logo 等授权真图
- **WorkBuddy 按《素材计划》生成：** 课程背景/功效/人群等主题插图（约 23 槽）
- **禁止：** 打开速福达金样 PPT 改字交付；禁止沿用金样插图像素
- 内容确认后才会批量生图；`approve visual --asset-bindings` 绑定本主题新图后才能出片
