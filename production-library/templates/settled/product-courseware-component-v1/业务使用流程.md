# 构件化商品培训 PPT · 业务使用流程

## 默认路线

`product-pptx-component-v1`（引擎 `courseware-pptx-v1` + `generate_courseware.py`）

## 五步

1. **选做什么**：门户选「构件化商品培训 PPT」或 CLI `business_job.py new --route product-pptx-component-v1`
2. **交内容**：主题 + 要点 notes；或完整 `script.structured.json`（`--script-json`）
3. **审初稿**：打开 `draft/内容初稿.md` 与 `script.structured.json`，确认无金样残留、无未审功效
4. **批准**：`approve --gate content`
5. **生成取件**：`render` → `05_交付物放这里/<job_id>/终稿.pptx`

## 纪律

- 文案只来自业务脚本；系统不扩写功效/剂量
- 无授权包装图用占位槽，不伪造
- 绿色五页壳 `product-pptx-green-v1` 仅兼容旧任务
