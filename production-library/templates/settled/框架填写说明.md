# 框架填写说明（全课型通用 · 业务 + 代理）

> 与业务包内同名文件保持一致。权威总案：`docs/business-workbuddy-foolproof-delivery.md`。

## 硬规则

1. **模块可删**：不需要的整节标题 + 内容直接删除。  
2. **有几条写几条**：联合用药 / 卖点 / 人群等列表按真实条数。  
3. **禁止空行凑满**：金样示例 3 行、业务只交 2 条 → 成品只出 2 行。  
4. **未提供不编造**：价格 / 功效 / 竞品无审核稿 →「待确认」或缺口。  
5. **无授权图不仿装**：包装 / Logo 无授权原图 → 槽位「待补」。

## 课型模块速查

| 课型 | 主要模块 | 不填时 |
|------|----------|--------|
| 绿色单品 PPT | 介绍、卖点、人群、联合、对标、注意 | 整节可省；联合 N→N 行 |
| 疾病+商品场景 PPT | 辨证、商品、销售场景 | 按资料裁剪 |
| 商品培训视频 | 分章旁白原文 | 章可删可排；屏显可后补确认 |
| 疾病科普视频 | 症状/机理/治疗/用药/总结 | 章可删；新病种量产前制作确认 |
| 课件3 / 课件4 | 视频章 + PPT 同源模块 | 同商品 PPT 规则 + 克隆声 |

## 提交与确认

- 提交：已填空白 Word + 授权图 + 口令（课型中文名 + 主题）  
- PPT：先内容初稿 → 确认 → PPTX  
- 视频：先分镜预览 → 确认 → MP4  
- 视频旁白：模板 `voice_id` 克隆，禁止系统机器人音色
