# 本课型怎么填 · 疾病+商品场景 PPT（如穿心莲）

- 产物：可编辑 PPTX
- 空白 Word：同目录 `业务提交_空白模板.docx`
- 填写参考：`../../03_填写参考/disease-product-scenario-v1/业务提交_填写参考.docx`（仅学格式）

## 推荐板块（可删可增）

1. 疾病/辨证知识
2. 商品知识
3. 销售场景与话术
4. 其他需要培训的板块（自定）

## 填写要点

- 板块按资料完整度裁剪；没有的整节删除。
- 填写参考若为他主题，只学结构不抄医学结论。

## 对话示例（复制给 WorkBuddy）

```
我要用【疾病+商品场景 PPT（如穿心莲）】，主题是【病名或商品名】。
请按金样结构整理内容初稿与素材计划后生成成片。
```

## 图片怎么来（重要）

- **业务提供：** 本品包装、权重/对标商品包装（授权真图）
- **WorkBuddy 按《素材计划》生成：** 疾病定义主图、症状、重点人群、日常护理等知识插图
- **禁止：** 打开穿心莲金样 PPT 改字交付；禁止沿用金样疾病/症状像素
- 内容确认后才会批量生图；`approve visual --asset-bindings` 绑定本主题新图后才能出片

## 列表 / 模块硬规则

- 有几条写几条；联合用药 2 组 → 成品 2 行
- 禁止空行凑满金样示例数
- 没有的板块整节删除
