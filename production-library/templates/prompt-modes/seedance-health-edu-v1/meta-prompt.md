# 【通用型】全场景科普视频：AI 视频生成架构（纯提示词版）

**模式 ID：** `seedance-health-edu-v1`  
**用途：** 将任意生活健康/安全常识主题填入 `[变量]`，展开为 Seedance 2.0 可复制提示词。  
**扩展原则：** 只换方括号变量，不重写「钩子 → 干货 → 演示 → 扩展 → 升华」骨架。

---

## 第一部分：【扁平头部 (Flat Header)】—— 视觉与合规锚定

**全局风格：** 3D Pixar 电影级画质，8K 渲染。光影采用 `[定义色调：如冷暖对比/明亮午后]`。强调 `[物理粒子：如雨水、尘埃、摩擦力]` 的超写实模拟。

**角色定义 (剧情动态)：**

- **角色 A（科普引导者）：** `[年龄/性别]`，身着 `[固定服装色块]`，表情亲切，具有「打破第四面墙」的交互感。
- **角色 B（场景体验者）：** `[年龄/性别]`，身着 `[对比色服装]`，负责演示错误/正确动作。

**核心资产：** `[定义主场景：如玄关、山间、厨房]`。

**合规逻辑（最高指令）：** 严禁白大褂、医疗器材及专业病理术语。将所有专业名词转化为「生活习惯、环境安全、情绪调节」。

**负面排除：** 无水印、无字幕、无跳切、无 2D 动漫感。

---

## 第二部分：【逻辑流叙事 (Logic-Flow Narrative)】—— 剧情与口播融合

此部分不设固定秒数，由 AI 根据剧情张力自动延伸物理交互。  
**落地 Seedance 时：** 默认拆为 5 段，每段 10–15 秒；可按主题合并为 3–4 段，单段仍 ≤15 秒。

### 1. 【反差感·痛点切入】(The Hook)

- **画面描述：** 镜头从 `[核心环境元素]` 特写切入，表现出一种「紧迫感」或「混乱感」。角色 A 突然出现在画面一侧，挡住部分背景，看向镜头，手指向身后正在发生的 `[痛点：如窗外暴雨/湿滑地面/焦虑的备考孩子]`。
- **物理模拟：** 强调 `[痛点元素]` 的动态力学（如：风吹乱头发、脚在湿地上的打滑感）。
- **口播台词：** 「家人们，`[核心痛点]` 这种事儿，咱真不能硬冲！看着这 `[环境状态]`，咱心里准在打鼓吧？」

### 2. 【秩序感·干货演播】(The Solution)

- **画面描述：** 背景虚化，角色 A 举起 `[交互媒介：如手机/指引卡片]`。画面浮现出 `[预警等级/分类图标]`，根据科普内容进行动态变色或脉动。角色 B 在背景中根据指引停下错误动作，转为观察。
- **物理模拟：** 手机屏幕的高光折射，图标在空中悬浮的微弱震动感。
- **口播台词：** 「别慌！认准这份指引：`[等级 A：如红色停课]` 咱就按兵不动；`[等级 B：如延迟上学]` 咱就稳坐泰山。安全第一，这才是聪明人的做法！」

### 3. 【沉浸式·细节避险】(Deep Dive)

- **画面描述：** 场景瞬间切换至 `[高风险环境：如狂风街头/山间]`。角色 A 亲自或指导 `[角色 B]` 演示关键动作。镜头聚焦于 `[关键部位：如脚部避开积水/手扶稳支点/避开大树广告牌]`。
- **物理模拟：** 强调 `[材质交互]`，如：雨水在雨披上的流淌感、风力拉扯广告牌的金属吱呀声。
- **口播台词：** 「尤其是这种时候，`[危险物 A]` 和 `[危险物 B]` 咱得绕着走！记住，`[免责/利好信息：如学校不记迟到]`，咱求的就是个踏实。」

### 4. 【避险常识·扩展场景】(Extreme Scenario)

- **画面描述：** 镜头拉远至 `[特殊场景：如野外、河道]`。展示 `[泥石流/山滑坡等极端情况]`。演示 `[逃生路径：向两侧高处跑，而非顺流跑]`。
- **物理模拟：** 模拟 `[极端动态：如山体滑坡的崩塌感/水流湍急的体积感]`。
- **口播台词：** 「万一在野外碰上 `[险情]`，千万别顺着跑！要往 `[正确方向]` 撤。这可是咱全家的保命智慧！」

### 5. 【利他性·情感结尾】(Social Wrap-up)

- **画面描述：** 阴霾散去，阳光穿透云层（上帝光效果）。两名主角在 `[安全环境]` 中并排，看向镜头露出温暖笑容并挥手。画面中心升起 3D 艺术字：「平安是福」。
- **物理模拟：** 温暖的阳光丁达尔效应，发丝边缘的金色光晕。
- **口播台词：** 「日子要过，安全要火。这份指引，赶紧转给咱身边的 `[目标人群]`。平安过春天，咱公园见！」

## 第三部分：【视频号发布全家桶】

- **标题模板：** `[情绪词]` + `[科普主体]` + `[人群/地区标签]` `[emoji]`
- **免责置顶：** 「⚠️ AI 生成技术辅助创作。本视频仅供生活常识分享，非专业医疗或应急决策建议。平安第一。」
- **定向转发：** 提供「利他性」转发语，如：「@老伴/孩子，这个避险视频讲得很清楚，为了全家安全，花 1 分钟看看。」

## 总导演提示

这套架构的优势在于**「可无限扩充」**。无论后续讲「居家防火」「春季舒压」还是「防跌倒」，只需将上述 `[ ]` 里的变量换掉，AI 就会自动根据「钩子-干货-演示-升华」的爆款逻辑生成完整视频剧本与画面描述。

### 填槽时的硬规则

1. 所有医学/应急专业词 → 生活口语（例：勿写「急性上呼吸道感染」，写「换季容易不舒服」类生活表述，且不做诊疗）。
2. 角色服装用**固定色块**锁定一致性（便于多段 Seedance 角色稳定）。
3. 每拍口播 ≤ 35 字为宜（适配 10–15 秒口播密度）。
4. 第 4 拍若主题无「极端野外」可改为**居家/通勤扩展场景**，结构保留「别做错方向」的对照。
5. 结尾 3D 艺术字默认「平安是福」；可按主题改为「慢一点更安心」等，仍须暖色收束。

### 代理展开 → Seedance 时的包装句式（每段开头复用）

```text
竖屏 9:16，3D Pixar 电影级画质，8K，[色调]。
角色 A：[描述与固定服装]；角色 B：[描述与对比服装]。
主场景：[核心资产]。
合规：无白大褂、无医疗器材、无专业病理术语；生活常识表达。
禁止：水印、字幕、跳切、2D 动漫感、文字 logo。
[本段画面 + 物理 + 口播 + 镜头]
```
