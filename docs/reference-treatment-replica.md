## 画面节点

1. 复用调理原则信息卡与大人物近景，完成前三句解释。
2. 直接切换“常用食材”三列卡：桑叶、菊花、薄荷。
3. 三张卡按旁白顺序依次出现青白高亮边框，其余卡保持正常状态。
4. 人物直接换位到左侧，三张卡缩到右上区域；不播放走路过渡。
5. 以程序化标尺展示“各 3–5 克”，随后出现原创桑菊薄荷饮杯。
6. 增加“喝 1–2 天”信息标签，停留后转入下一章节。

## 组件沉淀

- `HerbCard`：标题、图片、默认边框、高亮边框。
- `HerbGrid`：1–3 列卡片布局和逐项高亮时间轴。
- `DosageMeasure`：引线、刻度、剂量标签。
- `HerbalTea`：茶杯主图与程序化蒸汽。
- `BoundPresenter`：复用归一化嘴部锚点、闭口和三种开口嘴型。

## 素材规则

- 参考帧中的植物照片和茶杯仅用于构图、颜色和信息密度测量。
- 正式桑叶、菊花、薄荷和茶饮必须全部重新制作。
- 图片内不生成文字；所有标题、剂量和说明均由程序化文字层绘制。
- 植物主图最低 1024×1024，无水印、Logo、品牌包装或参考片像素。
