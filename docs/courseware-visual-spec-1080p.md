# 1080P 动画培训课件视觉规范 v2.0

适用范围：1920×1080、16:9 的连锁药店内部培训视频、网页课件与视频化 PPT。首阶段以公司现行参考视频为视觉母版；本规范中的推荐值来自参考帧比例，通用可读性标准只作为下限。

## 0. 参考帧量化基线

用户确认的“调理核心”参考帧为 2740×1512 的播放器截图。剔除播放器控件影响后，按画面比例换算到 1920×1080：

- 右侧药师从头顶到画面底部约占画面高度的 86%–90%，属于大人物近景，不是完整站立小人。
- 信息卡约占画面宽度的 55%、高度的 46%，人物与信息卡视觉边界间隔约为画面宽度的 4%–6%。
- 页面标题视觉字高约 68–76px。
- 卡片强调标签视觉字高约 50–58px。
- 正文视觉字高约 46–52px，行距约为字号的 1.35–1.5 倍。
- 字幕视觉字高约 48–56px。

后续模板先满足以上参考比例；只有信息量明显增加且无法分页时，才允许降低到本规范列出的最低有效字号。

## 1. 字体

- 中文字体：优先 `PingFang SC`，Windows 回退 `Microsoft YaHei`，最后回退无衬线字体。
- 标题使用 600–700 字重；正文使用 500–600 字重；字幕使用 700–800 字重。
- 不使用细体、长段全粗体、低对比灰字或仅依靠发光维持识别度。

## 2. 1080P 字号层级

| 层级 | 推荐源字号 | 动画缩放后的最低有效字号 | 用途 |
| --- | ---: | ---: | --- |
| 页面主标题 | 68–76px | 64px | 章节页、主题标题 |
| 核心结论 | 52–60px | 48px | 调理原则、商品核心卖点 |
| 卡片分组标题 | 48–54px | 42px | 全身症状、呼吸道症状 |
| 正文/摘要 | 46–52px | 38px | 症状列表、解释文字 |
| 图片标签 | 38–44px | 30px | 发热、口渴、咳嗽 |
| 视频字幕 | 48–56px | 48px | 画面底部单行字幕 |
| 辅助信息 | 32–36px | 28px | 页码、图例、次要提示 |

任何组件整体缩放时，必须按“源字号 × 缩放比例”复核有效字号。低于表中最低值时，应重排版，不能继续缩小。

## 3. 安全区与排版

- 左右内容安全区：至少 96px；顶部安全区：至少 54px。
- 底部 150px 作为字幕与章节导航区，正文和人物关键部位不得进入。
- 主标题与正文区域之间至少留 56px。
- 卡片内部左右留白不少于 40px，上下留白不少于 24px。
- 同一行最多 4 张症状图；每张图下方标签保持单行，不能压缩到 26px 以下。
- 一块信息卡最多承载一个分组标题、两行摘要和四张图。
- 正文单行建议不超过 18 个汉字；两行文字的行距为字号的 1.3–1.5 倍。

## 4. 数字人尺寸与站位

- 单人主讲页：有效可见高度建议为画面高度的 75%–90%。
- 人物与信息并列页：参考片近景为画面高度的 82%–90%；症状总览等高密度页面不得低于 68%。
- 人物视线或手势应指向信息区；人物与卡片视觉边界至少保持 56px。
- 不使用包含透明留白的图层边框尺寸判断人物大小，必须以头顶到脚底的实际可见像素计算。
- 人物嘴部状态必须覆盖讲话、停顿和末帧；闭口状态是独立嘴型，不是隐藏嘴层。
- 嘴型坐标必须使用相对角色宽高的归一化锚点，禁止把不同尺寸姿势的嘴部位置作为互不关联的像素常量维护。
- 每个姿势的无嘴母版必须在 400% 放大下确认无原嘴残留；脸部中心线与嘴型中心误差不得超过角色可见脸宽的 1%。

## 5. 色彩与对比

- 深色背景上的正文使用接近白色的高对比色；关键内容使用高明度青色。
- 正文与背景的对比度目标不低于 4.5:1；大标题不低于 3:1。
- 同一页面最多使用一个主强调色和一个辅助强调色。
- 发光仅用于层级提示，不得用发光代替字体粗细和对比度。

## 6. 出片验收

- 分别检查全屏信息页、人物并列页、动画缩放最小帧和最后一帧。
- 在 50% 预览比例下，标题、正文和图片标签仍应无需放大即可辨认。
- 检查人物有效可见高度、人物与信息区距离、字幕是否遮挡、卡片是否溢出。
- 最后一帧必须检查闭口位置、原嘴残留、双嘴、歪嘴和贴片边缘。
- 导出后检查 1920×1080、30fps、H.264/AAC、无黑帧。
