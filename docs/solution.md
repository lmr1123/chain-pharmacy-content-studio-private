# 连锁药店内部培训内容批量制作方案

## 1. 产品定位

产品名称暂定：**Chain Pharmacy Content Studio（连锁药店内容工厂）**。

它不是培训考试系统，也不是替代药师和法务的内容生成系统，而是一套面向总部内容团队的**批量制作工作台**：

> 将药师和合规法务已经审核通过的脚本、商品资料与品牌素材，批量转换成风格统一的培训视频和可编辑课件。

系统重点解决五件事：

1. 批量导入脚本；
2. 自动拆分分镜和课件页面；
3. 套用统一模板与品牌资产；
4. 自动生成配音、字幕、动效和排版；
5. 批量渲染、预览、局部返修和导出。

## 2. 对样片的拆解

用户提供的样片属于典型模板视频，结构为：

- 固定栏目片头；
- 标题和章节导航；
- 卡通讲解角色；
- 症状、要点、步骤等信息卡；
- 图片或商品包装展示；
- 固定字幕和配音；
- 总结页与片尾。

这类视频不需要每次从零剪辑。系统可以将脚本解析为结构化分镜，再根据每个分镜的类型选择对应组件：

| 脚本内容 | 自动匹配画面 |
|---|---|
| 标题、主题 | 片头或章节页 |
| 三个核心要点 | 三列要点卡 |
| 症状或适用场景 | 图标列表或人物场景卡 |
| 商品介绍 | 包装图、名称与说明卡 |
| 操作步骤 | 编号步骤卡 |
| 注意事项 | 警示卡 |
| 总结 | 四宫格或关键词总结页 |

因此，批量生产的关键不是让 AI 自由设计每一帧，而是建立稳定的“脚本结构 → 画面组件”映射。

## 3. 推荐生产流程

### 批量视频

审核脚本 Excel/Word → 内容结构解析 → 分镜草稿 → 模板套版 → 素材匹配 → 配音 → 字幕 → 时长计算 → 低清预览 → 人工局部调整 → 批量高清渲染

### 批量 PPT

审核内容 Excel/Word → 页面大纲 → PPT 母版套版 → 商品图与信息卡排版 → 预览 → 局部调整 → PPTX/PDF 导出

视频和 PPT 使用同一份结构化内容，这样一个商品或主题无需重复录入。

## 4. 输入格式

### Excel 批量表

建议一行代表一个视频或一个课件，至少包含：

- 任务编号；
- 内容类型；
- 标题；
- 已审核旁白；
- 章节标记；
- 画面提示；
- 素材关键词；
- 商品图片路径；
- 模板名称；
- 输出比例；
- 备注。

### Word/Markdown 单篇脚本

建议使用简单标记：

```text
# 标题

## 章节：典型表现
[旁白]……
[画面] 三列症状卡
[素材] 咽喉、咳嗽、发热

## 章节：注意事项
[旁白]……
[画面] 四条警示卡
```

系统只解析结构和制作指令，不主动改写已审核正文。需要改写时生成新版本并标记差异。

## 5. MVP 模板

### 模板 A：健康知识讲解

- 科技感或清新医疗风片头；
- 卡通药师/讲解员角色；
- 章节导航；
- 症状卡、步骤卡、图片卡、总结卡；
- 统一字幕、角标与片尾。

### 模板 B：商品知识培训

- 商品包装主视觉；
- 产品基础信息；
- 特点或说明要点；
- 适用场景/人群；
- 注意事项；
- 门店讲解提示；
- 总结页。

### 模板 C：商品培训 PPT

- 封面；
- 培训目标；
- 商品信息；
- 图文知识页；
- 要点对比页；
- 注意事项；
- 总结页。

首期模板数量应少而稳定。先把 3 套模板做透，再增加视觉风格，而不是一开始建设大量低质量模板。

## 6. 工作台界面

建议只有五个主要页面：

1. **批量任务**：导入 Excel、查看状态、批量生成和导出；
2. **任务编辑器**：左侧脚本，中间分镜/页面，右侧属性和素材；
3. **模板库**：管理视频与 PPT 模板；
4. **素材库**：管理商品图、人物、图标、背景、音乐和品牌资产；
5. **系统设置**：配音、字幕、输出规格和渲染设置。

不增加课程、班级、学员、考试等导航，避免产品偏离批量制作目标。

## 7. 推荐技术方案

- 前端：React / Next.js；
- 后端与任务编排：Python FastAPI；
- 视频模板：Remotion；
- 视频合成与转码：FFmpeg；
- PPTX：PptxGenJS；
- 数据库：首期 SQLite，团队部署时升级 PostgreSQL；
- 文件存储：本地项目目录或企业 NAS；
- 批量队列：首期使用轻量任务队列，规模扩大后再引入 Redis worker；
- 配音：可插拔 TTS；
- 图文生成：仅用于制作辅助，已审核正文作为锁定输入。

首期采用单体应用最合适：开发和部署更快，视频渲染等真正出现并发瓶颈后，再独立渲染 worker。

## 8. 关键制作能力

- 一份内容同时生成 16:9 视频、9:16 视频和 PPT；
- 自动测算旁白时长并调整镜头；
- 字幕自动断句和安全区检查；
- 缺失素材明确提示，不静默生成错误画面；
- 商品图支持自动抠图和统一留白；
- 批量替换品牌元素；
- 单镜头重新渲染；
- 已审核原文锁定与差异提示；
- 输出任务日志和素材清单，方便追踪返工原因。

## 9. 建议的首期验收

用用户提供的样片作为视觉参照，准备 20 份已审核脚本：

- 10 份健康知识内容；
- 10 份商品知识内容；
- 批量生成 20 条视频；
- 其中至少 5 份同时生成培训 PPT；
- 检查批量导入、模板一致性、字幕准确率、素材缺失提示、单条返修和导出成功率。

首期是否成功，不看系统有多少功能，而看内容团队能否把过去逐条制作的流程，变成“导入一批—预览修改—批量导出”。
