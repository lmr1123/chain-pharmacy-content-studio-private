# 连锁药店 AI 动画内容工厂 — 项目简报

更新日期：2026-07-31

## 1. 需求意图

公司需要一套使用 AI 批量制作内部培训内容的工作流，把药师和合规法务已经审核通过的脚本、商品资料和品牌素材，转换为：

- 健康科普动画视频；
- 商品知识培训视频；
- 商品培训课件；
- 可编辑网页演示；
- MP4、PPTX、PDF 和字幕等交付物。

目标不是做培训考试平台，也不是让 AI 生成药学结论。

## 1.1 推进原则（2026-07-30 锁定，防偏离）

**最重要的交付**是每一份高质量、风格统一、培训结构完整清晰的培训课件或视频，不是素材元件库。

**正确顺序：**

1. 选定/复刻**完整**高质量参考 → 金样签样；  
2. 从金样抽出**培训框架**与**系列风格**（`style_pack`）；  
3. 同风格延伸新主题（换审核内容，只补本课语义所需图）；  
4. 需要另一种结构时，再复刻第二份完整金样 → 第二套框架。

**视频扩展（2026-08-04 确认）：** 风格壳 + **段 recipe 库** + 主题填内容；段内 N 条自适应、空段跳过。详见 `docs/video-segment-extension-model.md`。
**禁止作为主进度：** 无金样槽位依据的大规模预囤通用元素（语义易对不上主题）。  
**真包装/Logo/证据：** 业务提供。  

登记：`decision.gold-sample-first`、`lesson.gold-sample-not-asset-stockpile`（`tasks/lessons.md`）。  
资产 registry / 外补 / gap 仅为金样槽位服务，冲突时服从本原则。

## 2. 最终目标

建立一套能够长期用于真实生产的垂直内容工厂：

1. 批量导入审核后的 Word、Excel 或结构化脚本；
2. AI 自动拆分分镜、提取屏显内容并选择专业场景；
3. 从企业素材库匹配人物、商品、医学插图和品牌资产；
4. 自动完成配音、字幕、动画节奏和场景时长；
5. 在网页中快速替换文字、素材、人物、动画和配音；
6. 单场景返修，不需要整条视频重新制作；
7. 批量输出视频和课件。

最终产物必须是可直接用于内部培训的高价值内容，不接受：

- 占位 SVG；
- 线框动画；
- 临时图标拼装（排版小符号可按需从已审计源头如 Koboyo 匹配，不得整库镜像或替代场景插画）；
- 只证明技术跑通、但不能交付使用的半成品；
- 依赖后续人工重新设计才能使用的初稿。

## 3. 参考样片说明

用户提供的三分钟样片和四张截图证明，这类内容已经能够通过模板化二维动画制作出来。

逐帧判断显示，参考视频主要由以下方式构成：

- 固定品牌或栏目母版；
- 二维人物、图片、商品图和文本图层；
- 位移、缩放、淡入、高亮和逐项出现；
- 卡通药师的嘴型、眨眼、表情和姿势序列；
- 配音、字幕和场景时长同步；
- 视频软件最终合成。

它不是生成式 AI 一键视频，也不依赖复杂三维动画或 Vyond 级通用角色系统。

## 4. 解决方案

最终推荐：

> AI 分镜导演 + 12–18 类专业动画场景 + 企业素材库 + 网页快速精修 + 开源程序化渲染。

### 内容层

- 审核旁白锁定；
- 旁白、屏显短句和画面提示分开保存；
- AI 只负责拆分、映射、检索和编排；
- 所有素材和改动可追溯。

### 视觉层

建立三类正式视觉主题：

- 深色科技医疗；
- 浅色医疗科普；
- 商品品牌展示。

首期重点场景：

- 栏目片头；
- 卡通药师讲解；
- 症状/特点卡；
- 机制流程；
- 商品包装主视觉；
- 适宜人群；
- 用法步骤；
- 注意事项；
- 对比说明；
- 总结页。

### 生产层

```text
审核脚本
  → AI 分镜和场景选择
  → Scene JSON
  → 企业素材匹配
  → 配音和字幕
  → 网页预览与精修
  → 批量渲染
  → MP4 / PPTX / PDF / SRT
```

### 技术方向

- 视频和网页预览：Revideo + FFmpeg；
- Web 工作台：React / Next.js；
- PPTX：PptxGenJS；
- 中文配音：先验证高质量 TTS，生产接口保持可替换；
- 卡通药师：预制姿势、表情、眨眼和嘴型序列；
- 真人数字人：作为增强场景，不是参考样片复刻的前置条件；
- 统一数据：Scene JSON；
- 批量任务：后端队列、单场景缓存和失败重试。

## 5. 关键决策

### 决策 1：不复制完整 Vyond/Animiz

项目不需要通用动画软件的无限自由，而需要少量高质量专业场景覆盖大量重复内容。

### 决策 2：不让生成式视频模型直接生成整条视频

整条自由生成无法稳定保持商品包装、中文文字、医学图示和品牌风格的一致性。

### 决策 3：视觉质量优先于编辑器功能数量

建设顺序固定为：

1. 视觉母版；
2. 人物、商品和医学素材；
3. 场景模板；
4. 动画节奏；
5. AI 自动编排；
6. 网页精修；
7. 更高级的时间轴与真人数字人。

### 决策 4：成片原理与参考作者相同，生产方式更自动

参考作者大概率逐条复制模板、替换内容和导出；本系统用 AI 和 Scene JSON 把这些重复操作批量化。

### 决策 5：样片必须直接使用拟生产的技术和资产标准

不采用“先做一个低质量演示、以后换引擎重做”的过渡路线。金标准样片从第一版就验证正式视觉资产、正式动画和可参数化场景。

### 决策 6：视频、网页和课件共用内容，不强求动画完全同构

- MP4 和网页演示保留完整动画；
- PDF 是静态版；
- PPTX 保留可编辑元素和适合演示的原生动画；
- 不承诺网页动画无损转换为 PowerPoint 动画。

## 6. 已沉淀教训

- “培训”不等于考试和学员管理；
- 内部药师和法务负责内容结论，系统负责忠实制作；
- 用户提出的 Vyond、Animiz、网页版和数字人是参考，不是预设答案；
- 高价值首先来自视觉母版、素材质量和信息设计；
- 参考样片应先逆向生产方法，再决定自动化方案；
- 卡通药师是二维嘴型和姿势动画，不是真人数字人；
- PoC 不能使用占位图和粗糙 SVG 冒充成片；
- 技术成功必须通过实际 MP4 和逐帧视觉 QA 证明。

## 8. 金标准样片验收

样片要求：

- 1920×1080、30fps；
- 时长 60–90 秒；
- 约 6 个完整场景；
- 深色科技医疗风；
- 原创卡通药师；
- 人物表情、眨眼和嘴型变化；
- 症状卡、机制/调理场景和总结页；
- 中文配音和逐句字幕；
- 章节导航；
- 无占位素材、无文字溢出、无素材变形；
- 同一场景数据可替换标题、旁白、重点词和主要素材。

评审后明确：

- 哪些画面达到参考；
- 哪些画面超过参考；
- 哪些部分仍需提高；
- 该路线是否进入批量工作流和网页编辑器开发。
