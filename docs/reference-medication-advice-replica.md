## 画面节点

1. “药物调理”页：角色位于左侧，第一张药品卡先出现，第二张药品卡随后出现。
2. 药品卡由无品牌包装主体、准确药名文字层和“包装示意”标记组成；不使用参考视频药盒截图。
3. 角色直接切换到中央展开双臂姿势，完成生活细节提醒；不播放走路过渡。
4. “生活禁忌与建议”页展示四条横向建议卡：保持通风、多喝温水、饮食清淡、戒烟戒酒/避免温补。
5. 四条建议按旁白顺序用白色外框和浅色底逐项高亮，前一项恢复青色常态。
6. 第四项讲完保持画面，下一段再切入“风热证总结”。

## 组件沉淀

- `MedicationCard`：包装主体、标题胶囊、药名、包装示意、入场动效。
- `AdviceRow`：序号、图标、短标题、说明文字、普通/高亮状态。
- `AdviceList`：1–4 条纵向布局和统一间距。
- `SequentialHighlight`：按语句时间窗切换高亮状态。
- `BoundPresenter`：复用已有归一化嘴部锚点与直接换位规则。

## 素材与合规边界

- 参考片药盒、图标和整页截图只用于构图、色彩与比例测量。
- PoC 使用全新生成的无字、无品牌包装主体；药名由程序文字层绘制。
- 包装必须标记为“包装示意”，不能冒充真实商品图、生产厂家或获批包装。
- 生产阶段可由公司替换成内部已授权且审核通过的正式包装图。
- 四个生活建议图标均为全新制作并保存透明 PNG、主图、缩略图与生成配方。
