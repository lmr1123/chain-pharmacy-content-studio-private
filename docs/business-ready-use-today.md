# 业务 + WorkBuddy：今天怎么用

**默认协作模型（已锁定）：**

> **业务**负责内容与确认 · **WorkBuddy**负责按 settled 模板出初稿与成片。  
> 不是「业务独自双击出片」，也不是「业务只能交材料、再等制作手工做」。  
> **标准路径不经过制作返修**；制作只处理异常/新页型/编辑器级返修。

**业务包：** `outputs/业务使用资料包/药店培训内容工厂-业务包.zip`  
**刷新：** `python3 scripts/refresh_business_delivery.py`  
**WorkBuddy 系统提示：** `docs/workbuddy-system-prompt.md`（代理电脑粘贴）

---

## 分工（一句话）

| 角色 | 做什么 | 不做什么 |
|------|--------|----------|
| **业务** | 看货架、选课型、填 Word、交授权图、审初稿/分镜、点确认、收成片 | 装 Node、起端口、调 TTS、改坐标/图层 |
| **WorkBuddy** | 锁定模板、解析 Word、内容驱动排版、列缺口、出初稿、确认后生成 PPTX/MP4、克隆旁白 | 把正常 settled 单甩回「请找制作」；编造医学结论；假包装；系统机器人音色 |

---

## 端到端（双方一起完成交付）

```text
业务                          WorkBuddy（同机或对接）
────                          ────────────────────
① 打开货架选课型
② 填空白 Word + 授权图
③ 发口令 + 附件        →
                              ④ 锁定 template / style_pack / voice
                              ⑤ 解析内容（N 条→N 行）
                              ⑥ 交「内容初稿 + 缺口」
                              　 或「分镜预览 + 缺口」
⑦ 审阅、改文案、确认   →
                              ⑧ 生成终稿 PPTX 和/或 MP4
⑨ 成片归档 / 门店使用
```

业务**不需要**自己点生成器；**需要** WorkBuddy 把 ④～⑧ 做完。  
有 WorkBuddy 时，业务侧交付闭环是完整的。

---

## 业务侧操作（你）

1. 解压业务包 → 双击 `01_模板货架/index.html`  
2. 选课型（优先「已签样 · 可换主题量产」）  
3. 读 `02_空白Word/…/本课型怎么填.md`，填空白 Word  
4. 复制 `04_WorkBuddy口令卡.md`，连 Word/图发给 WorkBuddy  
5. 对照 `06_你将收到的初稿长什么样/` 审初稿/分镜  
6. 用 `业务验收清单.md` 勾选；确认后要成片  
7. 成片放 `05_交付物放这里/`（或 WorkBuddy 写明的交付目录）

### 你有权这样要求 WorkBuddy

- 「联合用药我只写了 2 组，按 2 行排，不要空第三行」  
- 「先出初稿+缺口，我确认后再出 PPTX/视频」  
- 「旁白用模板药师克隆声，不要系统朗读」  
- 「没包装图就槽位待补，不要仿包装」

## WorkBuddy 侧必须做到（代理）

1. 加载 `docs/workbuddy-system-prompt.md`  
2. 用 `business-catalog.json` 把中文课型名落到 settled slug  
3. 列表/联合用药用 `scripts/content_driven_rules.py`  
4. **确认前**：只交初稿/分镜 + 缺口（模板在 `production-library/templates/business-delivery/`）  
5. **确认后**：按该模板 `manifest.json` 的 generator / 既有脚本真正产出 PPTX 或 MP4  
6. 交付目录写清；带 `template_id` / `style_pack_id` / `voice_id` 追溯  

正常换主题 **禁止**停在「请制作同事处理」——那是把业务+WorkBuddy 模型做废。  
仅当：新页型全库没有、金样冻结（如风热 visual-rework）、或渲染环境缺失时，才升级制作，并**明确告知业务卡点**。

## 能力对照（按 业务+WorkBuddy）

| 环节 | 状态 |
|------|------|
| 货架预览 + 空白 Word + 口令 + 验收清单 | **可用** |
| 初稿 / 缺口 / 分镜标准结构 | **可用** |
| 内容驱动 2→2 行规则 | **可用**（代码门禁） |
| WorkBuddy 确认后出绿色 PPT 等 settled 成片 | **代理应执行**（依赖本机工程与 manifest 生成入口） |
| 视频克隆旁白 | voice 已绑；本机 TTS 环境需就绪 |
| 制作返修（编辑器端口） | **非默认**；疑难才上 |

## 和「一键无人值守」的区别

- **我们做的：** 业务 + WorkBuddy 对话协作完成高质量交付（业务零工程操作）。  
- **我们没承诺的：** 业务电脑上没有任何代理、只双击 Word 就出片。  

你的目标是前者——文档与迭代均按前者验收。
