# 参考视频与截图制作方式逆向判断

## 1. 结论

参考内容不是通过生成式 AI 一次生成的完整视频，也没有体现出 Vyond 级别的通用角色动画能力。

它们的共同制作原理是：

> 审核脚本 → 人工分镜 → 固定视觉模板 → PNG/照片/商品图分层排版 → 基础进出场动画 → 配音和字幕 → 视频导出。

参考视频加入了一个会切换嘴型和表情的二维卡通药师，但它不是通常所说的真人数字人。

无法仅凭最终 MP4 确定作者具体使用了 PowerPoint、万彩、After Effects、剪映或其他软件。因为源工程已经被合成为单一视频，而且现有文件又经过一次转码，原始制作软件信息没有保留下来。

## 2. 可以从视频确认的事实

文件本身：

- 时长约 181 秒；
- 1920×1080；
- 30fps；
- H.264 视频和 AAC 音频；
- 文件标记为重新编码，编码器信息只能说明最终转码方式，不能证明原始制作工具。

画面结构：

- 全片复用同一个深色科技边框、背景和底部章节导航；
- 内容以标题、文本框、照片、图标和卡通人物的二维图层构成；
- 卡片主要使用位移、缩放、淡入淡出和逐项出现；
- 科技圆环、粒子和背景线条大概率来自循环动态背景或现成模板；
- 人物身体和手势以固定姿势为主，不存在复杂连续肢体动作；
- 连续帧显示人物嘴部在若干种预制嘴型间切换，并伴随眨眼；
- 不同段落通过整张人物姿势或表情素材替换来变化；
- 字幕已经烧录进画面；
- 医学人体图、食材照片和图标来自不同素材来源，再由统一边框和色板包装。

这些特征符合二维模板视频，而不是三维动画、自由生成式视频或高复杂度角色动画。

## 3. 最可能的现有生产流程

### 第一步：脚本和配音

作者先取得完整讲稿，再使用真人录音或 TTS 生成音频。根据配音时间确定每个章节和画面的停留时长。

### 第二步：人工分镜

作者把稿件拆成：

- 片头；
- 概念说明；
- 症状列表；
- 病因或机制；
- 食材或商品；
- 调理建议；
- 禁忌；
- 总结。

这一步大概率由人工完成，因为镜头内容与旁白含义对应，但没有表现出生成式视频的随机变化。

### 第三步：复制视觉母版

复制预先制作的：

- 深色科技背景；
- 左上角栏目 Logo；
- 底部章节导航；
- 卡通药师位置；
- 标题样式；
- 信息卡边框；
- 字幕区。

然后替换当期主题、文字和素材。

### 第四步：拼装素材

使用 PNG、JPG、SVG 或透明视频素材完成：

- 药师不同姿势；
- 口型和眨眼；
- 症状图标；
- 人体示意；
- 食材照片；
- 药品或商品包装；
- 科技装饰和循环背景。

### 第五步：添加基础动画

参考视频中主要需要：

- 透明度；
- X/Y 位移；
- 缩放；
- 裁切或蒙版；
- 高亮；
- 简单循环旋转和漂浮；
- 人物嘴型序列。

这些能力 PowerPoint、万彩、剪映、After Effects 和网页动画引擎都能实现。

### 第六步：字幕和最终合成

把配音、字幕、背景音乐和场景画面合成，最后导出 1080p MP4。

## 4. 具体软件的可能性

| 可能方式 | 与参考内容的匹配度 | 判断 |
|---|---:|---|
| PowerPoint/Keynote 制作画面，再到剪映合成 | 高 | 足以完成绝大部分卡片、流程、图片和进出场 |
| 万彩/Animiz/来画类动画软件 | 高 | 人物嘴型、模板场景和时间轴很匹配 |
| After Effects 模板 + Premiere/剪映 | 高 | 科技片头、HUD 和人物口型可实现，但人工成本更高 |
| 全程剪映/CapCut 图层和关键帧 | 中高 | 能做出来，但大量页面管理不如模板软件方便 |
| Vyond | 中 | 可以实现，但样片没有体现必须使用 Vyond 的复杂角色能力 |
| 生成式 AI 整条视频 | 低 | 统一排版、准确文字和商品素材不符合自由生成特征 |

最合理的判断是：作者使用了模板化动画工具或 AE/PPT 母版，随后在剪辑软件中完成配音、字幕和导出。

## 5. 四张截图分别是怎么做的

### 商品包装与三点卖点

本质是平面广告图：

- 产品图抠图；
- 番茄素材；
- 三行卖点和勾选图标；
- 水墨或纸张背景；
- 品牌 Logo。

静态版本可由 Photoshop、Canva 或 PowerPoint 完成；视频版本只需增加商品进入、轻微漂浮和卖点逐条出现。

### 番茄—细胞—肌肉

这是典型流程模板：

- 三张图标或插图；
- 两个箭头；
- 标题和少量文字；
- 节点依次出现或放大。

PowerPoint、万彩或 AE 都可以快速完成，不需要复杂 AI 视频模型。

### 适宜人群

这是人物素材卡片模板：

- 多张不同来源的插画；
- 人群标签；
- 依次出现或当前对象高亮。

难点不是动画，而是人物插画风格是否统一。

### 口腔溃疡商品组合

这是医疗培训 PPT/视频模板：

- 浅绿色医疗母版；
- 医生插画；
- 两个商品包装；
- 标题、连线和底部总结；
- 通过进出场动画变为视频。

## 6. 我们是否和他们一样

### 相同之处

我们应该沿用相同的视觉生产原理：

- 二维分层场景；
- 固定品牌母版；
- 有限种高频版式；
- 企业商品和医学素材库；
- 基础动画组合；
- 配音、字幕和画面同步；
- 最后渲染为视频。

这是参考内容能够稳定制作出来的真正原因。

### 不同之处

参考作者大概率是一条一条人工复制模板、替换内容并调整时间。

推荐系统是在其前面增加自动化层：

| 现有作者流程 | 推荐系统 |
|---|---|
| 人工阅读脚本 | AI 解析审核脚本 |
| 人工拆分镜头 | AI 先生成场景草稿 |
| 手动选择页面模板 | 按内容类型匹配专业场景 |
| 手动查找和插入素材 | 优先匹配企业素材库 |
| 手调每个动画和时长 | 动画预设和配音时长联动 |
| 单条导出 | 批量任务、失败重试和局部重渲染 |
| 依赖设计人员操作软件 | 网页中做受控修改 |

因此准确说法是：

> 成片的视觉原理和他们相同，但生产方式不完全相同。我们把他们的人工模板制作流程结构化、数据化和批量化。

## 7. 能否达到同样效果

参考内容中的以下部分可以直接作为首期能力：

- 深色科技或浅色医疗母版；
- 标题、章节导航和字幕；
- 症状、适宜人群、卖点和注意事项卡片；
- 商品包装组合；
- 图片、箭头和机制流程；
- 卡通药师的姿势切换；
- 简单嘴型、眨眼、漂浮和高亮；
- 1080p 视频输出。

这些效果不需要先实现完整 Vyond，也不需要真人数字人。

真正需要提前准备的是：

- 一套质量足够高的母版；
- 卡通药师的姿势、表情和嘴型素材；
- 统一风格的医学插图和人物素材；
- 高清商品包装图；
- 中文字体、色板和动画节奏规范。

如果这些素材到位，首期样片可以达到参考视频相同级别，并在图片清晰度、字体统一性和商品展示上超过参考内容。

## 8. 推荐取舍

不照搬作者可能使用的具体软件操作，因为那仍然需要设计师逐条制作。

应该复制的是其内容生产方法：

1. 固定母版；
2. 有限场景；
3. 分层素材；
4. 预设动画；
5. 统一配音字幕；
6. 最终合成。

然后用 AI 和程序化渲染替代重复的人工步骤。
