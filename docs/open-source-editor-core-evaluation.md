# 编辑路线验证结论

更新日期：2026-07-31

## 最终选择

个人内部使用阶段不再维护此前独立搭建的网页编辑器 PoC。当前保留的是 **Revideo 原编辑器内的轻量业务图层插件**：复用其时间线、预览和渲染，只补充模板内部已声明业务图层的直接操作、当前项目导出和模板候选版本保存。通过 `VectCutAPI` 写入剪映的方案只保留为场景片段、字幕、旁白和后加效果的单条精修通道。

结构化模板仍是批量生成的唯一源数据；剪映草稿是单条视频的最终编辑副本。剪映内调整不会自动反向覆盖正式模板，确认有复用价值的改动再人工回填为模板新版本。正式流程见 `docs/jianying-draft-template-workflow.md`。

## 已否决方案

- 自建场景编辑器：交互可验证，但需要继续维护布局、字体、素材、撤销和时间线，偏离视频成片主线。
- Fabric.js 技术稿：只证明多选与批量替换可行，整体界面不具备业务完成度。
- OpenVideo 验证稿：成熟度仍不足以替代剪映，且字体／远程素材稳定性和后续维护成本不适合个人内部验证。

以上三套验证代码已删除，仅保留本决策记录。正式 Revideo 金样、模板、素材和渲染入口未删除。

## Revideo 分层编辑复验结论（2026-07-30）

- 不再以剪映草稿承诺模板内部元素编辑。剪映仅保留为场景片段切分、字幕、旁白和后加效果的单条精修出口。
- 风热证正式 181.2 秒金样已整理为一个 7 场景 Revideo 项目，并在 Revideo 原编辑器内增加轻量业务图层插件；复用其既有时间线、预览和渲染，不另造一套编辑器排版。
- 当前已验证画布点选、拖动、拖拽缩放、Shift 多选、插图批量替换、撤销／重做、候选保存和刷新恢复。候选补丁也能注入无头渲染，不再只是浏览器临时视觉状态。
- 模板沉淀仍执行候选边界：编辑保存只生成 validation 候选；经业务目测确认后才允许转成 settled 模板新版本。当前批量替换两张症状图的候选是技术测试，不是正式模板。
- 结论是“Revideo 分层编辑技术链路通过、待业务手感验收”，不是恢复已删除的通用网页编辑器 PoC，也不改变 gold-sample-first 的生产顺序。

## 当前使用结论（2026-07-31）

- 已补齐画布点选、框选、拖动、四角缩放、旋转、Shift 多选、文字修改、图片单换／批量替换、撤销／重做和基础属性调整。
- 当前个性化修改可以不保存模板，直接导出完整 MP4 或 7 页原生可编辑 PPTX。
- 模板保存已改为“另存为新模板版本”：第一次点击只进入确认状态，10 秒内再次确认才保存；版本文件带毫秒时间和唯一短码，且使用排他创建，不覆盖 settled 原模板或历史候选。
- 当前进入**使用观察期**。暂停继续增加编辑器功能，先用真实业务任务判断哪些操作高频、哪些问题会实际阻塞交付，再决定下一轮最小迭代。
- 业务使用说明见 `docs/revideo-business-editor-usage.md`。

## 当前边界

- 剪映草稿的原生可编辑对象仍只有七段场景片段、旁白、逐条字幕及后加效果；片段内部图文、插图、组件和数字人动画已经烘焙，因此剪映业务元素级编辑性仍不通过。
- Revideo 业务插件可以操作已登记稳定 `layer_id` 的文字、图片和业务组合，但不支持任意新建图层、通用时间轴制作或无约束动画创作。
- Revideo 的复杂粒子、程序动画、口型绑定等能力不能可靠地转换成剪映原生对象；需要时以独立动画层进入剪映。
- 批量生产仍优先由结构化 `asset_slot_id` 在生成前替换；生成后的个性化小范围调整使用 Revideo 业务插件，最终节奏和音视频精修使用剪映。
