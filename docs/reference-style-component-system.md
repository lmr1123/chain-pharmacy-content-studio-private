# 参考视频样式组件体系

## 结论

首阶段采用“确定性场景配方 + 可编辑组件”，不是把素材和动效无规则随机拼接。输入仍是公司已审核脚本，AI 只负责拆分场景、推荐配方、匹配素材和生成制作清单；人物、文案、素材和时间轴均可人工修改。

## 单一验收基线

- 母版：以公司现行参考视频的深色背景、左上栏目标、底部章节导航、右侧内部培训声明为准。
- 角色：保持同一药师身份、发型、服装、比例和画风；讲话时身体锚点不动。
- 声音：首个复刻样片直接使用参考原声验证节奏；新脚本须使用已授权的企业音色或本地音色。
- 动画：口型和表情是局部高频状态；手势、走位、姿势是低频语义动作。
- 输出：当前签样为 1920×1080、30fps MP4；网页编辑、PPTX/PDF 是后续产品阶段，不提前视为已完成。

## 组件分类

| 类别 | 首批组件 | 可编辑参数 | 组合约束 |
|---|---|---|---|
| 品牌母版 | Logo、科技背景、章节导航、内部声明 | Logo、栏目名、章节、色板 | 全片唯一母版，不随镜头随机变化 |
| 片头 | 标题显现、轻微故障闪动 | 标题、持续时间、强度 | 只用于片头或大章节切换 |
| 药师角色 | 待机、讲话、指示、展开双臂、步行 | 站位、缩放、朝向、动作段 | 讲话不切整身；步行结束后才能切语义姿势 |
| 面部状态 | 闭口、小口、圆口、大口；后续补眨眼/眉形 | 音素、持续时间、强度 | 只覆盖局部透明图层，不改变头身锚点 |
| 信息卡 | 症状标签、两行症状图组、图片说明卡 | 文案、图标、图片、强调色 | 受安全区和最大字数限制 |
| 机制表达 | A＋B→C、流程节点、因果链 | 节点、连线、强调状态 | 每镜头只保留一个主要运动焦点 |
| 字幕 | 单行/双行底部字幕 | 文案、字号、断句、时码 | 不遮挡导航、角色关键动作和声明 |
| 转场 | 淡入、推入、节点触发、角色走位 | 方向、时长、缓动 | 同一镜头不叠加多个主转场 |

## 角色状态机

```text
侧边待机
  └─ 开始讲解 → 稳定身体 + 局部口型
       ├─ 重点提示 → 低频指示手势 → 回到稳定讲话
       └─ 章节结束 → 停口 → 直接换位到中央
                         └─ 展开双臂 → 触发下一节点
```

核心规则：

1. 角色外层容器负责位置、缩放和旋转，所有姿势共享脚底基线。
2. 正常讲话只切换透明口型，不替换整身图片。
3. 眨眼必须使用独立眼睑/眼睛层；若出现脸部矩形接缝，当前镜头宁可不眨眼也不放行。
4. 当前参考模板的章节换位采用直接切换，不播放走路或连续位移动画。
5. 动作由脚本标签选择，如 `explain`、`point`、`walk_to_center`、`open_arms`，不做无条件随机。

## 场景配方示例

```json
{
  "sceneType": "mechanism_equation",
  "narration": "简单来说，风热证就是风加热一起入侵身体。",
  "presenter": {
    "entry": "left",
    "speech": "stable_local_mouth",
    "exitAction": "walk_to_center",
    "nodeAction": "open_arms"
  },
  "content": {
    "left": "风邪",
    "operator": "+",
    "middle": "热邪",
    "result": "入侵身体"
  },
  "transition": "node_trigger",
  "seed": 20260729
}
```

固定种子只用于同一场景配方中可替换的微变化，例如卡片进入次序；不能改变品牌母版、主色、角色身份或信息层级。

## 当前样片已经验证

- 参考片头、母版、Logo、章节导航和内部声明；
- 同一药师角色在侧边稳定讲解；
- 局部透明口型切换，不再引发整身抖动；
- 侧边讲解结束后按参考片直接换位到中央；
- 换位后展开双臂并触发“风邪＋热邪→入侵身体”节点；
- 使用参考原声、字幕和原节奏完成 28.23 秒闭环。

## 仍需在下一签样补齐

- 独立眼睛/眉毛分层后的无接缝眨眼与关切表情；
- 对完整参考视频中的症状图组、调理建议、禁忌、总结等组件逐项复刻；
- 新文案的授权音色 A/B，而不是继续复用参考原声；
- 浏览器时间轴编辑和 MP4/PPTX/PDF 多格式导出。
