# 商品培训参考片高忠实复刻返工规格

## 返工原因

首版商品培训签样只验证了结构化字段、旁白和 Revideo 渲染链路，但视觉上改成了另一套浅色现代卡片设计，删除了参考片的大部分人物、插图和镜头内动画。该版本不能作为视觉签样。

返工重新采用项目内已通过的 faithful reproduction 标准：

- 参考视频是唯一首阶段视觉基线；
- 使用连续参考片段，不把不相邻页面拼成“代表性”改版；
- 母版、人物比例、文字尺度、图文密度、动画顺序和实际时码逐项测量；
- 参考截图只用于测量和风格对标，正式资产重新绘制或重新生成；
- 技术可编辑性保留在底层，但不能替代可见成片的复刻质量。

## 首个返工范围

- 参考片：20.38–49.44 秒；
- 独立复刻段：29.06 秒；
- 起点：人体自身合成的辅酶 Q10 减少之后，进入“缺乏后果”；
- 终点：商品包装英雄镜头结束，下一镜开始品牌与商品总览。

选择这段是因为它在连续 29.06 秒内同时覆盖：

1. 卡通讲师及表情/口型；
2. 三张症状插图逐项出现；
3. 疾病—成分—治疗场景关系图；
4. 商品包装切换和放射式强调背景；
5. 黄色黑边字幕和右侧内部培训声明。

## 母版量化

- 画布：1920×1080、30fps；
- 主背景：高明度蓝色，叠加低对比度方框纹理；
- 左上标签：橙红色圆角胶囊，文字“辅酶Q10”；
- 右侧声明：竖排粉红底白字，贴近右侧安全区；
- 字幕：画面下方居中，黄色粗体、黑色描边，不使用深色整条字幕底；
- 内容白板：约占画面宽度 69%、高度 75%，深蓝色顶边；
- 人物：讲解近景约占画面高度 83%；白板并列时约占画面高度 58%，贴右侧；
- 商品英雄镜头：包装位于画面中心，背景为蓝/青/黄放射线，包装持续轻微缩放强调。

## 正式资产清单

### 必须重新制作

- 女讲师：正面待机、手掌解释两种姿势；
- 女讲师局部口型：闭口、小口、圆口、大口；
- 女讲师眨眼层；
- 疲劳乏力、心慌气短、胸闷心悸三张圆形插图；
- 蓝色方框母版与放射线背景；
- 疾病关系图节点、连线和白板。

### 当前缺失但影响 100% 忠实度

- 能气朗包装高清原图；
- 能气朗/远大医药 Logo 源文件；
- 原始讲师角色源图或矢量工程。

缺失项不得用参考截图裁切进入生产组件库。首轮可以使用重新生成的近似包装和重新制作的角色验证动画与构图，但必须明确标注“重新制作近似资产”；获得内部原图后再进行最终像素级替换。

## 验收

1. 参考帧与复刻帧按 21.5、24.5、27.5、30.5、34.5、40.5、42.5、48.5 秒并排；
2. 检查人物有效高度、白板宽高、插图间距、节点位置、包装占比和字幕基线；
3. 检查每个逐项出现节点不早于对应旁白；
4. 检查人物身体不随口型抖动，原嘴与新口型不叠加；
5. 检查参考截图像素未进入生产资产；
6. 通过 TypeScript 类型检查、完整解码、黑场、末帧和 50% 预览可读性检查；
7. 用户视觉评审通过前，不把该段标记为视觉签样完成。
