## 0. 现在能做什么 / 不能做什么

| 你想做的事 | 是否开放 | 业务怎么选 |
|------------|----------|------------|
| 沿用金银花绿色五页框架 | ✅ 固定标准课型 | 「绿色商品培训 PPT（金银花固定课型）」 |
| 做疾病知识 + 商品 + 场景的 18 页课件 | ✅ 固定标准课型 | 「疾病+商品场景 PPT（穿心莲固定课型）」 |
| 沿用速福达课件3的 13 页框架 | ✅ 固定标准课型，仅 PPTX | 「商品培训课件3 PPT（速福达固定课型）」 |
| 做 20 页成分健康科普（米白番茄红） | ✅ 固定标准课型 | 「番茄红素成分健康科普 PPT（米白番茄红）」 |
| 未匹配上述固定结构的灵活商品 PPT | ✅ 通用兜底 | 由 WorkBuddy 推荐「构件化商品培训 PPT」 |
| 出一份**商品讲解完整视频 MP4** | ✅ 路线开放，电脑环境要齐 | 「商品培训视频」+ 授权包装图 |
| 做 Seedance / 九宫格健康短视频 | ✅ 本机先出复核与提示词包 | 最终视频须到即梦/Seedance 等外部平台生成 |
| 给已确认课件做真人数字人侧讲 | 🟡 条件式人工 SOP | 双确认和环境/账号/授权条件齐备后才制作 |
| 速福达课件3新主题 MP4 | ❌ **尚未上线** | 目前只选课件3 PPTX；不承诺 MP4 |
| 疾病/健康科普视频（如风热证） | ❌ 暂未业务自助 | 仅可看金样；正式自助另专项 |

> 2026-08-09 业务验收决定已取代旧“绿色五页下线”状态：固定 5 / 18 / 13 / 20 页都是一等高保真路线；自然语言命中固定结构时优先走对应课型，只有未匹配时才用构件化灵活兜底。构件化不是把新商品直接套进福尔 16 页。

> 新红色课型真值：`ingredient-health-edu-pptx-v1` 已 active，可自助生成。`template.kangaisen-lycopene-health-edu-v1` 是 20 页**成分健康科普**，不是福尔课件4；正式换主题要求 69 个本主题显式新图绑定并完成 content + visual（`product_image=false`）。业务提供已审核医学/健康口径与可授权图片，WorkBuddy 不得继承康爱森/番茄红素金样文案或原图。

**原则（四条红线）：**

1. 医学/功效/剂量只来自**你们审核过的稿**，系统不替你编。  
2. **没确认初稿，不出正式成品。**  
3. **没公司授权的包装图/Logo/证据，不伪造**；可以保留草稿缺口，但不能发布正式稿。
4. 构件化商品 PPT 按**内容 → 视觉（插图绑定）→ 商品图（业务授权包装）**三道确认；三条商品固定课型也必须完成内容、商品图、视觉确认；番茄红素成分健康科普走**内容 + 视觉**（`product_image=false`）。全部课型均须逐页 QA，任何缺口/占位/金样残留都不交付。

## 1. 业务怎么用（推荐：WorkBuddy 对话）

业务**不必**自己敲命令。在 WorkBuddy 里按下面说即可。

### 1.1 第一次：安装 / 更新（仅需有权限的人做一次）

对 WorkBuddy 说（或按公司下发的安装句）：

> 请安装/更新连锁药店培训内容工厂（Private 生产仓），装完后打开业务引导页。

装好后本机应能打开业务门户（模板货架）。若提示「不是 Private 生产仓 / 无权限」，找管理员开 GitHub 权限，不要用未授权镜像。

### 1.2 日常：先用自然语言选课型，再出商品培训 PPT

安装后的统一主入口：

- 在门户点 **「我不懂模板，帮我选」**，复制自然语言口令给 WorkBuddy；或
- 直接告诉 WorkBuddy 交付目标、主题和已有资料。WorkBuddy 内部运行 `business_job.py recommend --text '<自然语言需求>'`，给出 1 个推荐；确有歧义时只给 2 个候选并问 1 个问题。

推荐只负责选型，不会创建任务。WorkBuddy 应解释课型、交付物、固定/动态结构和待补资料；你确认课型后才建草稿。

- 明确要金银花绿色 5 页、穿心莲疾病-商品-场景 18 页、速福达课件3 13 页或米白番茄红成分科普 20 页：优先选择对应固定课型；它们不是“参考样片”，而是可生成的一等高保真路线。
- 只有不匹配固定课型、需要页数和大纲灵活编排的普通商品 PPT，才推荐**构件化商品培训 PPT**；它不直接继承福尔 16 页页序、文案或原图。
- 明确要 20 页米白番茄红成分健康科普框架：选择**番茄红素成分健康科普 PPT**；该 route 已 active，可自助生成，但不得与福尔课件4混用。
- 速福达课件3当前只交 PPTX；不要因为目录里有金样 MP4 就选择或承诺新主题 MP4。

如果命中灵活构件，业务只需要提供**交付目标 + 已有内容**，不需要准备结构化 JSON、页型 ID 或命令参数。WorkBuddy 会根据内容在内部选择页序，并先展示一份可读的中文方案供确认：

1. 中文页签大纲及顺序；
2. 每个页签借鉴的已签样结构和复用边界；
3. 整套课件采用的唯一视觉风格。

当前可复用的跨课型能力包括：绿色课型的「商品信息总览」、穿心莲课型的「门店咨询框架」、速福达课件3的「商品证据阶梯」，以及已经登记并接入的新页型（例如「异议与升级」）。复用的是信息层级和页型合同，不是把不同课型的母版、文案或原图拼在一起；同一份课件必须锁定一个 style pack，所有页面在该视觉下统一生成。

素材分工固定如下，不由每一单临时决定：

| 类别 | 谁负责 | 典型内容 | 验收要求 |
|---|---|---|---|
| 商品/品牌事实 | 业务提供 | 正式包装、Logo、标签、备案/批准、检测或工艺证据 | 只用授权真图；缺失时明确列入缺口，不 AI 仿造 |
| 教学与场景插图 | WorkBuddy 自动生成或取已批准素材 | 成分知识、作用过程、食物来源、咨询人群、安全核对 | 按模板真实图槽比例与裁切生成；业务不执行提示词 |
| 模板公共构件 | 模板复用 | 版式、字体、色板、箭头、勾选、分隔线 | 只用已签样 style pack / component |

内容确认后，WorkBuddy 应先把 1 张代表图放入真实 PPT 图槽检查，再自动补齐同系列图片；不是先批量做整页海报。

对 WorkBuddy 说：

> 我要做一份**普通商品培训可编辑 PPT**，请先帮我选择合适课型。
> 商品名是【×××】。  
> 培训要点如下：  
> 1. ……  
> 2. ……  
> 3. ……  
> 如果推荐灵活构件，请先给我**中文页签大纲、来源解释和单一视觉说明**；我确认编排后，再整理**内容初稿、缺口清单和素材计划**。**确认前不要创建正式任务或生成正式 PPT**。

系统应：

1. 复述已锁定的模板中文名与交付物（若未选模板，先推荐并等待选择）
2. 构件化路线先展示**中文页签大纲 + 来源解释 + 统一视觉说明**，此时不创建任务、不锁正式页序
3. 业务确认上述方案后，WorkBuddy 才在内部生成确认版正式脚本、创建统一任务，并生成**内容初稿**（你能看懂的 Markdown）+ **缺口清单** + **素材计划**
4. 等你确认初稿，并收齐业务提供的授权包装图/Logo/证据
5. 内容确认后，由 WorkBuddy 按固定图槽生成/绑定非商品插图并完成**视觉确认**；最后绑定你提供并确认授权的**正式商品包装图**
6. 构件化路线按内容 → 视觉 → 商品图三道确认齐全后生成 **可编辑 PPTX**，逐页 QA 通过才放入业务包「05_交付物放这里」

你确认时建议这样说：

> 初稿我看过了，以当前内容为准，**批准内容**。请先按图槽生成并绑定非商品插图供我确认视觉；最后使用我提供的公司授权包装图完成商品图确认。逐页 QA 通过后再交付正式 PPT。确认人：【你的姓名】。

取件后：用 WPS / Office 打开 `终稿.pptx`，检查页数、文字是否可改、有没有别的商品字样。

### 1.3 日常：出商品完整培训视频（可选）

前提：本机视频环境已就绪（旁白 TTS + 渲染包 + ffmpeg）。不确定时让 WorkBuddy 先查：

> 请检查本机商品完整视频环境是否就绪（video_full）。

若就绪，再说：

> 我要做**商品培训完整 MP4**。  
> 商品名是【×××】。  
> 授权包装图路径是【本机图片路径】。  
> 旁白/分段要点是：……  
> 请先出脚本初稿，我确认内容后再确认包装图，最后再渲染正式视频。

正式视频需要两道确认：**内容** + **授权包装图**（带凭证说明）。

### 1.3.1 四种视频辅助模式的真实产物

| 模式 | WorkBuddy 本机能直接交什么 | 最终视频由谁生成 |
|---|---|---|
| Seedance 生活避险 | 脚本复核包；确认后的分段提示词与发布包 | 业务使用即梦/Seedance 外部账号出片 |
| 九宫格原版 | 六段口播复核、角色三视图提示词、九宫格/视频提示词与发布包 | 业务选择的外部图片/视频平台出图、出片 |
| 九宫格合规版 | 脱敏口播复核、视觉资产提示词、九宫格/视频提示词与发布包 | 业务选择的外部图片/视频平台出图、出片 |
| 真人数字人侧讲方案 C | 先交全课旁白脚本和数字人关键页清单；它是人工 SOP / 条件式制作，不是本机一键自助路线 | 双确认后，关键页才调用 HeyGen；其余页本机合成 |

前三种模式的“本机生成成功”只代表**复核包/提示词资产生成成功**，不代表 MP4 已生成。数字人方案 C 必须先分别确认最终脚本和数字人页清单；双确认前禁止调用 HeyGen，也禁止克隆正式旁白终轨。继续制作还必须具备：可用 HeyGen key/额度、已确认的可编辑课件、授权人像，以及本机 Qwen TTS、rembg、ffmpeg。

### 1.4 工程师代跑时的等价命令（业务可不看）

```bash
# 统一主入口：只推荐，不建任务；业务确认后再使用 recommendation.route_id
python3 scripts/business_job.py recommend --text '我要做普通商品培训可编辑 PPT，商品是……' --json

# 以下为确认后命中“构件化商品培训 PPT”的内部示例；业务不接触脚本文件
python3 scripts/business_job.py new --route product-pptx-component-v1 \
  --theme "商品名" --script-json "/WorkBuddy内部任务区/确认版脚本.json" --auto-draft
python3 scripts/business_job.py approve --job <任务ID> --gate content --by "姓名"
python3 scripts/business_job.py approve --job <任务ID> --gate visual \
  --by "姓名" --asset-bindings "/路径/asset-bindings.json"
python3 scripts/business_job.py approve --job <任务ID> --gate product_image \
  --by "姓名" --product-image "/路径/授权包装图.png" \
  --authorization-reference "凭证编号或说明"
python3 scripts/business_job.py render --job <任务ID>
python3 scripts/business_job.py open --job <任务ID>

# 商品 MP4（环境齐时）
python3 scripts/business_job.py new --route product-mp4-full-v1 \
  --theme "商品名" --notes "…" --product-image "/路径/包装图.png" --auto-draft
python3 scripts/business_job.py approve --job <任务ID> --gate content --by "姓名"
python3 scripts/business_job.py approve --job <任务ID> --gate product_image \
  --by "姓名" --authorization-reference "凭证编号或说明"
python3 scripts/business_job.py render --job <任务ID>
```

构件路线的 notes-only 入口只生成“待确认中文页签大纲”草稿，绝不能作为正式锁定编排；业务确认大纲、来源解释和单一视觉后，由 WorkBuddy 内部生成确认版 script-json，再创建统一任务。固定 5 / 18 / 13 / 20 页课型和商品视频仍按各自既有 notes/Word 草稿入口执行，不受这条构件规则影响。

状态查询：`python3 scripts/business_job.py status --job <任务ID>`

### 案例 A · 自然语言推荐到构件兜底（商品名 + 几条要点）

**场景：** 店员内部商品培训，只要可编辑 PPT；审核要点还不全，先出结构再补。

**你对 WorkBuddy 说（第 1 轮）：**

```text
我要做普通灵活的商品培训可编辑 PPT，请先帮我选择合适课型。
商品名是：舒心维C咀嚼片（演练）。
培训要点：
1. 补充维生素C，适合日常饮食不均衡人群（待药师口径确认）
2. 咀嚼方便，门店主推话术强调依从性（待确认）
3. 联合推荐可搭配基础营养品，不硬凑处方药（待确认）
请先给我中文页签大纲、来源解释和单一视觉说明；我确认编排后再整理内容初稿、缺口清单和素材计划，确认前不要创建正式任务或生成正式 PPT。
```

**第 1 轮你应先看到：**

- 推荐为灵活构件课型，并给出**中文页签大纲、来源解释和单一视觉说明**
- 此时还没有任务 ID，也没有正式锁定页序

**你对 WorkBuddy 说（第 2 轮 · 先确认编排）：**

```text
这个中文页签大纲、来源解释和单一视觉方案可以，请按这个方案整理初稿。内部脚本和页序由你处理，不要让我填写。
```

**确认编排后你应看到：**

- WorkBuddy 内部生成确认版脚本并创建统一任务（有任务 ID）
- 有一份可读的 **内容初稿**（封面名是「舒心维C咀嚼片（演练）」）  
- 有 **缺口清单**（规格、审核功效、联合场景等可能仍待确认）  
- **还没有** 正式 `终稿.pptx`

**你对 WorkBuddy 说（第 3 轮 · 内容仍不完整）：**

```text
初稿我看过了，但待确认字段不能进正式稿。
请继续保留为 UAT 草稿，列出还需我补齐的审核内容和正式商品图；不要生成或发布终稿。
```

**你应拿到：**

- 更新后的缺口清单和素材计划
- 状态仍为「等待内容确认/等待业务资料」
- UAT 隔离区与正式 `05_交付物放这里` 均没有发布 `终稿.pptx`

**对应测试：** TC-PPT-02 + TC-PPT-03 + TC-PPT-07

### 案例 B · 构件 PPT（完整审核内容）

**场景：** 药师/合规已给完整审核内容，希望 WorkBuddy 按内容选择合适页签并锁定文案后再出 PPT。

**准备：** 在对话中粘贴审核内容，或提供业务 Word/附件，并准备本品授权正式包装图。业务不编写结构化 JSON、不选择页型 ID；这些由 WorkBuddy 内部整理。禁止仅替换金样商品名后沿用金样正文。

**你对 WorkBuddy 说：**

```text
我要做普通商品培训可编辑 PPT，页数按下面的审核内容灵活编排；请先帮我确认课型。
商品名是【×××】；审核内容是【粘贴内容或说明附件】。
请先给我中文页签大纲，逐项说明借鉴了哪类已签样结构，并说明整套课件采用什么统一视觉。
我确认大纲前，不要锁定页序；我确认内容前，不要生成正式 PPT。
```

**确认中文大纲后：**

```text
这个中文页签大纲和来源解释可以，按当前顺序整理内容初稿。内部页型和 JSON 由你处理，不要让我填写。
```

**确认内容后：**

```text
脚本内容确认，确认人：李四。正式包装图已附上。
请按素材计划先做 1 张代表图实槽检查，再自动补齐其余教学/场景插图，完成逐页质检后生成正式 PPT。
```

**你应看到：**

- 初稿中的功效/联合/注意与业务审核内容一致，系统**没有**另编未提供的功效

## 2. 测试案例怎么用

- **测试人：** 业务或运营；旁观记录：产品/工程师

- **记录：** 每个案例勾「通过 / 失败 / 阻塞」，失败写一句现象即可  
- **总通过标准：** 构件兜底 **TC-PPT-01～05、TC-PPT-07～09** 与固定路线 **TC-FIXED-01～04** 全部通过，才算「业务能自助出高质量 PPT」

## 5. 常见问题（业务向）

**Q：初稿里很多「待确认」正常吗？**  
正常。表示还没写入审核结论；你补齐并确认后再生正式稿。

**Q：可以只在 PPT 里大改字交差吗？**  
小改版式可以；**大改功效/话术**请回到任务改内容并重新确认，避免下次生成又覆盖、也避免无审稿。

**Q：取件在哪？**  
业务资料包目录下的 **`05_交付物放这里/<任务ID>/`**。WorkBuddy 可以说「打开取件目录」。

**Q：失败了怎么办？**  
任务会停在「环境不足 / 质检失败」等状态，**不会**假装已交付。把任务 ID 和屏幕提示转给支持同学即可。

**Q：绿色金银花、穿心莲和速福达这些模板是只能看参考吗？**
不是。绿色 5 页、穿心莲 18 页、速福达 13 页和成分健康科普 20 页都是一等高保真固定 **PPT** 路线，可由 WorkBuddy 走完整流程真实生成。构件化 PPT 只在自然语言没有匹配固定结构时作动态兜底，也不是直接套福尔 16 页。

**Q：速福达课件3能同时生成 MP4 吗？**
目前不能。新主题只支持 13 页可编辑 PPTX；金样目录里有历史 MP4 不等于 `courseware3-mp4-v1` 已上线。

**Q：番茄红素成分健康科普 PPT 是福尔课件4吗，现在能直接生成吗？**
不是。它是独立的 20 页米白番茄红成分健康科普课型，当前已可自助生成。正式任务必须使用业务审核口径，完成 content + visual 确认并显式绑定 69 个本主题新图（`product_image=false`）；不能继承康爱森/番茄红素金样文案或原图。
