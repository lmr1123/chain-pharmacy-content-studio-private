## 触发语（业务侧）

以下任一说法启用本模式：

- 「Seedance 科普」「生活避险科普」「扁平头部五拍」
- 「用元提示词扩展主题脚本，复制到 Seedance」（且主题为生活避险向）
- 「全场景科普 / 扁平头部那套」

若只说「健康科普视频」未指明：先问「九宫格林医生线，还是 Seedance 生活避险线？」

**不要** 误切到：

| 业务其实想要 | 正确线 |
|--------------|--------|
| 店员内部培训病种片（风热/感冒 MG 风） | `疾病科普视频` → `generate_business_video.py --template health` |
| 关键页真人数字人 | `数字人模式` scheme C |
| 可编辑培训 PPT | settled 课件课型 |
| 中老年 60s + 九宫格 + 林医生/王大爷 | `jiugongge-health-edu-v1` |

## 强制流程（不可跳步）

```text
① 锁定本模式 + 收集主题变量（最少：主题一句 + 目标人群）
② 用 meta-prompt 填满 [变量] → 输出《科普脚本复核包》
③ 业务确认文案/合规后（说「可以生成提示词」或「脚本通过」）
④ 展开为 Seedance 2.0 分段提示词（每段 ≤15s）+ 发布全家桶
⑤ 业务复制到即梦 / Seedance 2.0 出片（本仓库默认不代跑付费生成）
```

| 闸门 | 规则 |
|------|------|
| 合规最高指令 | **严禁**白大褂、医疗器材、专业病理/处方术语；全部转成「生活习惯、环境安全、情绪调节」 |
| 医学越界 | 不出现诊断、疗效承诺、药品用法用量；药店可做常识分享，须带免责 |
| 业务确认 | 改口播/改痛点后须再确认；未确认可出变量草案，**不**当终稿交付 |
| 出片费用 | 本模式默认只交**可复制提示词**；即梦/Seedance 额度在业务账号。**禁止**默认用用户付费 API 批量出片 |

## 叙事骨架（5 拍 · 可无限换主题）

对应元提示词「逻辑流叙事」：

| # | 拍 | 作用 |
|---|-----|------|
| 1 | 反差感·痛点切入 (Hook) | 紧迫感 + 角色 A 破第四面墙 |
| 2 | 秩序感·干货演播 (Solution) | 指引/分级/口诀浮现 |
| 3 | 沉浸式·细节避险 (Deep Dive) | 关键动作演示 |
| 4 | 避险常识·扩展场景 (Extreme) | 极端/扩展场景 + 逃生路径 |
| 5 | 利他性·情感结尾 (Wrap-up) | 阳光收束 + 「平安是福」+ 转发动机 |

主题扩展时**只替换变量槽**，不重写骨架。

## Seedance 2.0 输出约定

单次生成上限 **4–15 秒**。5 拍叙事默认拆成 **5 段**（或按张力合并为 3–4 段），每段独立可复制。

### 每段提示词必须包含

1. **全局锚定**（扁平头部浓缩版：3D Pixar、色调、角色服装色块、主场景、合规、负面排除）  
2. **本段画面 + 物理模拟**  
3. **口播台词**（引号标注，口语化）  
4. **镜头/时长建议**（默认竖屏 9:16 视频号；业务另指定则改）  
5. **禁止项**（无水印、无字幕、无跳切、无 2D 动漫感；无白大褂/医疗器械）

### 分段衔接

- 第 1 段正常生成；第 2–N 段可用「视频延长」或独立生成后剪辑拼接。  
- 每段结尾写清**衔接点画面**，方便延长模式。

### 平台限制（代理须提醒业务）

- 不要上传**写实真人脸**参考图（会被拦截）。本模式角色为 **3D Pixar 风格**，纯文本即可。  
- 即梦账号额度与是否可商用由业务自核。
