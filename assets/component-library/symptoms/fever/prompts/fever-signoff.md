# “发热”组件风格签样配方

## 固定风格语法

- 用途：内部健康科普动画的症状插图组件；
- 画布：正方形，主图不小于 1024×1024，四周保留约 10% 安全区；
- 媒介：二维健康科普卡通，深棕色统一线稿，扁平色块，少量柔和阴影；
- 构图：单人居中上半身，小尺寸仍能辨认症状；
- 背景：单一主题色背景、浅色圆形光晕、少量症状符号；
- 禁止：文字、Logo、水印、医疗器械、多人、照片质感、3D、恐怖表达。

## 可替换变量

| 变量 | “发热”取值 | 后续示例 |
|---|---|---|
| `subject` | 青年患者 | 儿童、老人、药师、顾客 |
| `expression` | 疲惫、轻微难受 | 疼痛、咳嗽、口渴、烦躁 |
| `body_signal` | 额头和面颊潮红、汗滴 | 红肿、黄痰、舌象、鼻涕 |
| `symbol` | 上升热浪 | 咳嗽气团、水滴、疼痛闪电 |
| `palette` | 珊瑚红、桃色、奶油色 | 根据主题映射 |
| `background_pattern` | 热感圆形光晕 | 呼吸波纹、局部聚焦、器官轮廓 |

## 候选方向

### A：忠实精细

保留参考片的暖红色症状语义，使用较细致的赛璐璐阴影和成熟青年人物。适合大画面展示，但批量扩展时细节成本较高。

### B：扁平亲和

减少阴影和发丝细节，强化一致线宽、圆润五官和小尺寸识别度。最适合作为当前科普视频组件库的默认候选。

### C：圆润高级

保持扁平基础，增加更统一的角色比例和少量高级感。适合后续建立跨疾病主题的统一人物系统。

## 通用负面约束

不要复制参考人物、发型、姿势或热浪排列；不要出现文字、边框、Logo、水印、诊断设备、额外人物、裁切头部、写实照片、3D、华丽动漫、婴儿化比例、火焰或恐怖痛苦表情。
