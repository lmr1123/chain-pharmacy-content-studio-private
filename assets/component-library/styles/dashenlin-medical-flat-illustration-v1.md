# 大参林商品课件医药扁平插画 v1

状态：`candidate`  
兼容风格包：`style-pack.dashenlin-courseware-green-v1`

## 用途

用于商品培训 PPTX 的辅助说明插画，特别是注意事项、适宜人群、生活建议和非证据型场景。参考公司课件 04“注意事项”页的视觉语言重新生成原创画面，参考截图只用于风格分析，不进入生产资产。

## 视觉语法

- 二维扁平医药科普插画，成年人也适用的亲和、克制表现；
- 紧凑圆润的成人比例、头部略大但明显是成年人，五官简化；
- 中等偏粗深绿色圆润线稿，4–6 种主要颜色；
- 平整柔和色块，几乎不使用渐变、纹理和高光；
- 浅薄荷绿或暖白背景，以大参林品牌绿为主；
- 少量青绿、米黄和珊瑚红用于提示，不混入其他模板画风；
- 方形 1:1 构图，主体居中，所有人物和物件完整收在画面内，四周至少 15% 安全区；
- 不在图片内绘制卡片边框、标题区或课件文字。

## 医学与品牌边界

- 图片只表达输入主题，不新增症状、药品、疗效、治疗方案或医学结论；
- 不生成文字、字母、数字、药名、剂量、疗程、禁忌、功效结论、Logo、二维码或水印；
- 不仿造真实药品包装、说明书、检测报告、处方或品牌证据；
- 需要药品物件时，只能使用无标签、无识别信息的通用简化药盒或药瓶；
- 不使用写实照片、3D、恐怖病变、血腥手术或夸张痛苦表达；
- 避免错误手指、异常肢体、物体穿插、器械结构错误和不合常识的医患动作。

## 输入和输出

业务只填写：

```text
使用位置：04 注意事项
图片主题：药师提醒成年患者清淡饮食，餐桌上有蔬菜和清淡食物
补充要求：人物动作自然，画面亲和克制
```

项目通过 `poc/courseware-export/text-word-import/image_prompt_protocol.py` 组合完整提示词。可调用生图工具时生成候选图；不可调用时输出同一提示词供业务复制到其他系统。

输出要求：

- 单幅方形 PNG；
- 建议不低于 1536×1536；
- 无文字、无水印；
- 生成状态固定为 `candidate`；
- 药师内容审核和视觉复核均通过后，才可粘贴到正式 PPTX；
- 该风格不能用于真实包装、说明书、检测报告、处方或品牌证据。

## 签样门

批量生成前先完成一张“药师提醒成年患者清淡饮食”代表图，检查：

1. 主题与审核原文一致；
2. 画风、线宽、色板和人物比例匹配；
3. 人物肢体、手指、医疗物件和动作合理；
4. 无文字、Logo、水印和真实包装仿造；
5. 小尺寸 PPTX 使用时仍可识别；
6. 药师内容审核和用户视觉签样完成。
