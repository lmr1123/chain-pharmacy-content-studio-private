# 蓝青医学机理可视化系列 v1

稳定 ID：`asset-series.mechanism.reference-medical-tech-v1`

本系列把可复用对象分成六类：正面全身人体、器官躯干、正面症状聚焦、解剖剖面、病邪体积介质和过程路径。新主题优先增加系列成员，再使用已有面板、药师、字幕和动画契约组合成视频或课件。

## 新增流程

1. 查询系列和角色，确认现有成员不能直接表达主题。
2. 从 `asset-template.json` 创建候选清单，绑定同一个 `style_pack_id`、`series_id` 和 `role_ids`。
3. 使用 `series.json` 中的色板、材质、构图安全区和动画契约生成代表资产。
4. 完成视觉、技术、来源和医学四项审核；每项单独记录，不继承其他成员状态。
5. 更新 `mechanisms/registry.json` 的成员关系，并让组件通过稳定资产 ID 引用。

系列负责统一视觉和组合接口，不负责自动批准医学内容。未来增加风寒、湿热、燥邪、胃肠、心血管等主题时，若仍能使用本系列语言，应增加成员而不是重新创建近似画风。
