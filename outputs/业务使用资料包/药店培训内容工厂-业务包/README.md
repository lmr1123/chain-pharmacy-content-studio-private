# 药店培训内容工厂 · 业务包（档 A）

**默认用法（推荐）：业务不必自己解压本包。** 在 WorkBuddy 输入：

```text
请安装 https://github.com/lmr1123/chain-pharmacy-content-studio.git，然后指引我使用
```

WorkBuddy 会安装仓库、打开本引导页，并陪你完成下面四步。

## Getting Started（开源式四步）

1. **预览选模板**（`index.html` 第 2 步）  
2. **按 Word 填报**  
3. **上传提交**（聊天附件 / 本页拖入 / `07_业务填报上传/待处理/`）  
4. **审初稿 → 收成片**  

离线备用：若已拿到本目录/zip，也可双击 `index.html` 自助浏览；正式出片仍需 WorkBuddy。

| 目录/文件 | 用途 |
|-----------|------|
| **`index.html`** | **主入口 · 分步引导** |
| `00_一页怎么用.md` | 文字版（含安装句） |
