# 内部培训 · 业务引导包

## 使用方法

1. WorkBuddy 输入：

```text
请安装 https://github.com/lmr1123/chain-pharmacy-content-studio-private.git，然后指引我使用
```

2. 打开 **`index.html`**（唯一业务入口）：
   - 选金样模板，看关键页预览
   - 在页面内查看**金样内容组成**，用「复制金样内容组成 / 复制给 WorkBuddy」粘贴对话
3. 在 WorkBuddy 说主题与要点 → 确认初稿 → 下载或改 PPT/视频

**不需要**下载或填写 Word。口令卡见 `04_WorkBuddy口令卡.md`。

| 业务会点开的 | 说明 |
|--------------|------|
| **`业务从零上手-WorkBuddy.md`** | 第一次怎么用（从零教学） |
| **`index.html`** | 模板预览 + 内容示例 + 复制粘贴口令 |
| `05_交付物放这里/` | 正式成品落点 |

## 素材边界（业务）

- **要交的**：审核文案（对话粘贴即可）、授权包装/Logo/证据（如有）；商品视频成片前还要确认绑定内容和包装图哈希的审批记录。<br>
- **不用交的**：箭头/序号/分行点等排版小图标、Word 空白表、通用物件符号——由代理按模板匹配。  
- **禁止**：用未授权网图冒充正式包装或证据。
