# 内部培训 · 业务引导包

## 使用方法

1. WorkBuddy 输入：

```text
请安装 https://github.com/lmr1123/chain-pharmacy-content-studio.git，然后指引我使用
```

2. 打开 `index.html`：**看模板**（一行四个小卡片 + 关键页预览）  
3. WorkBuddy **输入培训内容** → **下载 PPT 修改，或输入指令批量修改**  

示例口令见 `04_WorkBuddy口令卡.md`。

| 业务会点开的 | 说明 |
|--------------|------|
| **`index.html`** | 仅两块：模板预览选择 · **内容示例直接展示** |
| `03_填写参考/` | 源 docx（页面已内嵌正文，无需下载） |
| `02_空白Word/` | 代理侧可选 |
| **`08_数字人侧讲模式/`** | **真人数字人侧讲**：先审脚本+数字人页清单，确认后再生成 |

## 数字人模式（摘要）

1. 说「用数字人模式」  
2. 先收 **旁白脚本 + 哪些页有数字人**  
3. **业务确认后**才生成数字人（确认前不产生数字人费用）  
4. 全课同一药师克隆声；非关键页全宽讲解、不站静帧人  

详见 `08_数字人侧讲模式/README.md`。

## 素材边界（业务）

- **要交的**：审核文案、授权包装/Logo/证据（如有）。  
- **数字人模式另要**：脚本确认 + 数字人页码确认。  
- **不用交的**：箭头/序号/分行点等排版小图标、通用物件符号——由代理按模板与按需源头匹配。  
- **禁止**：用未授权网图冒充正式包装或证据。
