# 药店培训内容工厂 · 业务包（档 A）

本包可直接发给一线业务，**无需**安装开发环境。

## Getting Started（开源式）

1. 解压本包  
2. **双击根目录 `index.html`**（推荐主入口）  
3. 按四步：了解 → **预览选模板** → **填 Word** → **上传提交**  
4. 把口令 + 附件发给 WorkBuddy；先审初稿，再收成片  

| 目录/文件 | 用途 |
|-----------|------|
| **`index.html`** | **主入口 · 分步引导** |
| `00_一页怎么用.md` | 文字版四步 |
| `01_模板货架/index.html` | 仅货架浏览 |
| `02_空白Word/` | 空白模板 + 本课型怎么填 |
| `03_填写参考/` | 仅示范格式 |
| `04_WorkBuddy口令卡.md` | 口令 |
| `05_交付物放这里/` | 成片归档 |
| `06_你将收到的初稿长什么样/` | 初稿样例 |
| `07_业务填报上传/` | Word/图提交箱 |
| `业务验收清单.md` | 确认前核对 |
