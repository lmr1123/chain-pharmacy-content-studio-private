# 健康科普 Seedance 模式 · 代理执行清单（WorkBuddy 内部）

**禁止对业务念本文件路径堆。** 对业务只用「科普脚本复核包」和人话。

权威：

- `docs/seedance-health-edu-video-mode.md`
- `production-library/templates/prompt-modes/seedance-health-edu-v1/meta-prompt.md`
- `production-library/templates/prompt-modes/seedance-health-edu-v1/variables.schema.json`

---

## 闸门（不可违反）

```text
业务确认脚本之前
  → 可以：填变量、出《科普脚本复核包》
  → 不要：把未确认稿当「终稿提示词」强推复制出片

合规
  → 严禁白大褂 / 医疗器材 / 病理术语
  → 全部转生活习惯、环境安全、情绪调节
  → 必须带免责置顶文案

费用
  → 默认只交付可复制提示词
  → 禁止默认调用用户付费 API 批量生成即梦成片
  → 与「疾病科普视频」Remotion 本机出片线勿混
```

## 流程

| 步 | 动作 | 输出给业务 |
|----|------|------------|
| 1 | 识别本模式触发语；说明与「疾病科普培训片」区别 | 一句话定位 |
| 2 | 收主题 + 目标人群（缺则问一句，不连环问） | — |
| 3 | 读 meta-prompt + schema；填 `00-主题变量.json` | — |
| 4 | 填《科普脚本复核包》 | **复核包** |
| 5 | **等待**确认句 | — |
| 6 | 展开 5 段（或 3–4 段）Seedance 提示词，每段 ≤15s | `02-…md` |
| 7 | 标题 + 免责 + 转发语 | `03-…md` |
| 8 | 写 DELIVERY.md；可选 `scripts/scaffold_seedance_health_edu.py` | 路径 |

交付根目录：

`outputs/business-video-runs/seedance-health-edu/<主题-slug>/`

## 业务确认句识别

视为通过：

- 「脚本通过…可以出 Seedance 提示词」
- 「可以生成提示词」
- 「确认，按这个出提示词」

视为未通过：

- 只说「不错」「再看看」
- 仍在改口播/场景且未再说确认

---

## 分段提示词最低结构（每段）

1. 竖屏 9:16 + 3D Pixar + 色调 + 角色服装色块 + 主场景  
2. 合规句 + 负面排除  
3. 本段画面 + 物理模拟  
4. 口播（引号）  
5. 时长建议 + 衔接点（第 2 段起）  

参考包装句式见 `meta-prompt.md` 文末。
