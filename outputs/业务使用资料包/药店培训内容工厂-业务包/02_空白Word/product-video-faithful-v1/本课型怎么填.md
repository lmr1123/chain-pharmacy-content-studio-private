# 本课型怎么填 · 商品培训视频（如辅酶 Q10）

- 产物：MP4
- 空白 Word：同目录 `业务提交_空白模板.docx`
- 填写参考：`../../03_填写参考/product-video-faithful-v1/业务提交_填写参考.docx`（仅学格式）

## 推荐板块（可删可增）

1. 为什么要了解本商品
2. 商品基础信息
3. 核心功效 / 证据（审核稿）
4. 产品特点
5. 适宜人群
6. 联合用药（有几组写几组）
7. 总结

## 填写要点

- 一份 Word 一个商品；章节可删可重排。
- 包装图粘贴授权原图；无图则删除图片行，系统记缺口。
- 正式旁白 = 审核原文 + 模板 voice 克隆。

## 提交口令（复制给 WorkBuddy）

```
我要用 【商品培训视频（如辅酶 Q10）】，主题是 【病名或商品名】。
Word 和授权图在附件。
请先出 初稿/分镜预览 + 待确认项 + 缺图清单；
我确认后再出 可编辑 PPTX / 培训视频。
```

## 联合用药 / 列表硬规则

- 有几条写几条；2 组 → 成品 2 行
- 禁止空行凑满金样示例数
- 没有的板块整节删除
