# 真人数字人侧讲模式 · 业务怎么用

**模式名：** 数字人模式 / 真人数字人侧讲  
**模式 ID：** `digital-human-presenter-scheme-C`  
**更新：** 2026-08-08  

适合：疾病健康知识培训课件等，需要「像真人培训师在关键页出镜讲解」的成片。

---

## 你只要记住四步

```text
① 拉最新仓库 / 安装
② 选用「数字人模式」（或说：这个课件用数字人侧讲）
③ 先审「内容脚本 + 数字人页清单」→ 你确认后，才允许生成数字人
④ 收成片；要改再指令修改
```

**关键闸门（不可跳过）：**  
脚本与「哪些页有数字人」**必须先经业务确认**，再生成数字人（产生费用）。未确认前，代理**不得**调用 HeyGen。

---

## 第 1 步 · 安装 / 更新（复制到 WorkBuddy）

```text
请安装 https://github.com/lmr1123/chain-pharmacy-content-studio.git，然后指引我使用
```

若已装过，直接说：

```text
请 git pull 拉最新，然后指引我使用数字人侧讲模式
```

---

## 第 2 步 · 选用数字人模式

任选一种说法：

```text
这个课件用数字人模式 / 真人数字人侧讲来做
```

```text
按方案 C：关键页数字人，其余页全宽课件 + 旁白
```

同时给出主题与要点，例如：

```text
主题：急性上呼吸道感染培训。用数字人模式。
请先整理每页旁白脚本，并标明哪些页会出数字人，给我确认后再生成。
```

---

## 第 3 步 · 业务复核（生成前必做）

代理会发给你一份 **《数字人模式 · 业务复核包》**，至少包含：

| 材料 | 你看什么 |
|------|----------|
| **全课旁白脚本** | 文案是否专业、口语是否合适、有无医学越界 |
| **数字人页清单** | **明确写清：第几页、节名、为何出镜**；其余页无人但有旁白 |
| **时长与费用粗估** | 动态数字人合计约几分钟、是否在 1～3 分钟预算内 |
| **布局说明** | 关键页：课件收窄 + 人在侧；非关键页：全宽放大、不站静帧人 |

### 你需要回复的确认句（示例）

```text
脚本通过。数字人页确认：第 3、9、15 页。可以生成。
```

或：

```text
把数字人从第 9 页改到第 8 页；第 4 页旁白第二段改成……确认后再生成。
```

**在你说出「可以生成 / 确认生成」之前：不会产生数字人费用。**

---

## 第 4 步 · 生成与下载

确认后代理才会：

1. 用**统一药师克隆声**生成全课旁白  
2. 仅对**已确认的关键页**生成数字人并合成  
3. 非关键页：全宽课件 + 同声音旁白  
4. 把成片路径发给你  

要改：直接说页码与改法，代理改脚本后**若动到数字人页旁白**，会再次请你确认是否重渲数字人。

---

## 业务要交 / 不用交

| 要交 | 不用交 |
|------|--------|
| 审核通过的文案 / 脚本确认 | 自己调 HeyGen、自己抠像 |
| 关键页清单确认（或改页号） | 自己装 TTS、调语速参数 |
| 授权人像/包装（若换 IP） | 找工程师跑命令 |

---

## 和普通 PPT / 普通视频的区别

| | 普通 PPT | 数字人侧讲模式 |
|--|----------|----------------|
| 人 | 无 | 仅关键页动态数字人 |
| 非关键页 | 全宽课件 | 全宽课件 + **旁白**（无人） |
| 生成前 | 可较快出稿 | **多一道脚本+关键页确认** |
| 声音 | 克隆声 | **全课同一克隆声**（与数字人一致） |
