# 国内扁平卡通健康 MG 动画 · 业务怎么用

**模式名：** 国内扁平卡通健康 MG / 健康科普 MG 复用  
**模式 ID：** `domestic-flat-cartoon-health-mg-v1`  
**更新：** 2026-08-10  

适合：需要**统一画风、可换主题**的健康科普 MG 讲解片（口号钩子 → 数据/风险 → 自测/管理 → 行动号召）。  
**不适合：** 只要一句提示词外包到即梦/Seedance 的短视频（请用 Seedance 模式）；也不等于已 settled 的正式全片金样模板。

---

## 你只要记住四步

```text
① 打开业务门户 →「动画与数字人制作模式」→ 国内扁平卡通健康 MG
② 看演示样片 + 七张关键画面截图
③ 把「选用」口令贴给 WorkBuddy，补主题与审核要点
④ 先确认配方与样片，再换主题出分层预览 MP4
```

**关键点：**  
- 复用的是**镜头配方 + 模块槽**（城市分层、黄板、食谱轮播、CTA 板等），不是整段参考视频像素。  
- 门户样片用于**演示画风与结构**；全片视觉签样、正式旁白/字幕仍按闸门推进。  
- 机构名单、医学数据必须用**业务审核稿**，不能照搬演示样片里的本地示例。

| 模式 | 差异 |

## 诚实边界（演示时请一并说明）

1. 门户可看演示，**不等于**已登记 settled 正式模板。  
2. 批次视觉仍有待业务签样项；演示精选镜头用于画风沟通。  
3. 换主题后必须重新过医学与文案审核，不得直接继承演示片数据与机构电话。
