# 业务从零上手：在 WorkBuddy 做内部培训课件

> 给业务同事看的「第一次怎么用」说明。  
> 你只做三件事：**看金样 → 说内容 → 确认后下载**。  
> **不需要** 下载 Word、填空白表、找小图标、改代码。

---

## 0. 你会用到的两个东西

| 东西 | 是什么 | 你怎么用 |
|------|--------|----------|
| **WorkBuddy** | 聊天窗口（像微信一样对话） | 发口令、贴内容、要改页、下载成品 |
| **引导页 `index.html`** | 业务包里的网页门户 | 看金样预览、看每页写什么、一键复制口令 |

业务包位置（任选其一打开）：

- 下载文件夹：`Downloads/药店培训内容工厂-业务包/`
- 或解压后的同名文件夹

**唯一业务入口**：双击打开 **`index.html`**（用浏览器打开即可）。

---

## 1. 第一次：安装项目（只做一次）

打开 **WorkBuddy**，在对话框里**整段复制粘贴**下面这句话，发送：

```text
请安装 https://github.com/lmr1123/chain-pharmacy-content-studio-private.git，然后指引我使用
```

等它装完，并回复「已就绪 / 可以开始」之类提示后，再往下做。

以后若要更新到最新版，可以说：

```text
请 git pull 拉最新，然后指引我使用
```

---

## 2. 打开引导页，选一个「金样」

1. 打开业务包里的 **`index.html`**
2. 页面上是一排**金样卡片**（已签样的标准模板），例如：
   - **绿色单品 PPT（如金银花露）** — 商品培训 5 页
   - **课件 3 / 课件 4** — 其他商品培训版式
   - **疾病科普视频 / 商品培训视频** — 视频类
   - 下方还有 **制作模式**（数字人、科普动画等）— 那是「怎么拍/怎么讲」，不是换课型
3. **点开一张卡片**：
   - 看**关键页预览图**（长什么样）
   - 看 **「· 金样内容组成」**（每一页真实写什么，例如金银花露 5 页结构）
4. 心里确认：「这次培训要做成这种样子」

### 不会选模板时

不必在网页上纠结。直接在 WorkBuddy 用大白话说：

```text
我要做商品培训 PPT，主题是×××，大概讲卖点、人群、联合用药。请按已签样金样帮我选模板并说明理由。
```

它会对照货架推荐，**确认模板前不会偷偷开任务**。

---

## 3. 把「金样内容组成」复制到 WorkBuddy（推荐路径）

在引导页展开的金样详情里：

1. 点 **「复制金样内容组成」**  
   或 **「确认选用 · 复制给 WorkBuddy」**
2. 回到 **WorkBuddy**，**粘贴**
3. 在粘贴内容**下面**，用自己的话补上本次主题，例如：

```text
（上面是门户复制的金样结构，保留页序）

本次主题：可可康灵芝胶囊
请按该绿色单品 5 页结构整理内容，再生成 PPT。
要点：
1. 宁心安神助睡眠
2. 提升免疫力
3. 保肝护肝抗衰老
规格 / 价格 / 编码：（有就写，没有写「待确认」）
联合用药：（有几组写几组，不要凑满示例条数）
医学功效以我们审核稿为准，没有的不要编。
```

### 也可以不打开门户、直接说

适合你已经很熟、或主题很简单时：

```text
整理可可康灵芝胶囊商品，主要是围绕宁心安神助睡眠、提升免疫力、保肝护肝抗衰老3个方面来完善，你先整理符合内容再生成ppt
```

两种方式都对；**第一次建议走门户复制**，页结构更清楚。

---

## 4. 先看「初稿」，再点头出成片

WorkBuddy **不会**一上来就丢最终 PPT/视频交差。正常顺序：

| 顺序 | 你会收到 | 你要做什么 |
|------|----------|------------|
| ① | **内容初稿**（文字结构：每页标题、要点） | 对不对、缺不缺、有没有乱编 |
| ② | **缺口清单**（缺图、缺规格、待确认项） | 能补就补；补不了可先槽位 |
| ③ | 视频类还有 **分镜预览** | 过目屏显短句 |
| ④ | 你说「可以出成片 / 确认」 | 才出正式 PPTX 或 MP4 |

确认口令示例：

```text
初稿可以，按这个出成片。
```

或有小改再确认：

```text
第二页卖点第 2 条改成……；联合用药只保留 2 组。改完再出成片。
```

## 5. 下载与改稿

成片生成后，WorkBuddy 会告诉你**本机路径**；正式件也会进业务包里的：

`05_交付物放这里/`

### 改 PPT（对话即可）

```text
第二页卖点改成……
批量把联合用药改成 2 条
第三页删掉品种对标，整节省略
```

也可以下载 PPT 自己改字；结构大改仍建议对话批量改，避免版式跑掉。

### 改视频

```text
症状段旁白改成……，屏显同步改，再出一版
```

## 6. 你要交什么 / 不用交什么

| 要交 | 不用交 |
|------|--------|
| 审核过的培训文案（对话粘贴即可） | Word 空白表 / 填写表 |
| 有授权的包装图、Logo、证据图（按课型） | 箭头、序号、勾叉等排版小图标 |
| 商品**视频**正式成片前：业务确认过的包装图 + 内容绑定确认 | 自己找网图「像包装」的图 |

**禁止**：用未授权网图冒充正式包装或证据。没有图时可以说「包装待补，先出初稿」。

---

## 7. 内容怎么写才不返工（三条铁律）

1. **有几条出几条**  
   金样示例若是 3 组联合用药，你只交 2 组 → 成品只出 2 行，**不要空第三行凑满**。
2. **没有的不编**  
   价格、功效、竞品没有审核稿 → 写「待确认」或放进缺口清单，不要让 AI 编医学结论。
3. **金样定长相，你定内容**  
   页序/绿色视觉跟金样；文案、包装、插图换成你们审核稿与授权图。

## 8. 用「绿色单品 PPT」走通第一遍（建议练手）

目标：做出一份商品培训 5 页 PPT。

1. **安装**（第 1 节口令）
2. 打开 `index.html` → 点 **「绿色单品 PPT（如金银花露）」**
3. 看预览 + **金样内容组成**（封面 + 01 介绍/卖点/人群 + 02 联合用药 + 03 品种对标 + 04 注意事项）
4. 点 **复制金样内容组成** → 粘贴到 WorkBuddy
5. 把金银花露改成你的商品名与要点（条数按真实写）
6. 等**内容初稿** → 按《业务验收清单》过一遍 → 说「可以出成片」
7. 下载 PPT；若要改：「第二页……」

金样页结构对照（金银花露真实组成，换主题时保留结构、换文案）：

| 页 | 写什么 |
|----|--------|
| 封面 | 品名、单位、角标 |
| 01 | 商品介绍 + 核心卖点 + 适宜人群 |
| 02 | 联合用药话术（场景 / 组合 / 话术，有几组写几组） |
| 03 | 品种对标（可选；没有可整节省略） |
| 04 | 注意事项 |

## 9. 制作模式（数字人 / 科普动画）怎么用

货架下半部分是**制作方式**，不是换另一套课型：

| 模式 | 你先做什么 | 确认前系统不会 |
|------|------------|----------------|
| 数字人侧讲 | 先收「全课旁白脚本 + 数字人页清单」 | 不生成数字人、不调外部制作 |
| 健康科普 Seedance / 九宫格 / MG | 先收复核包 / 变量清单 | 不擅自开拍 |

口令骨架：

```text
这个课件用数字人模式做。主题是：×××。
要点：……
请先整理「全课旁白脚本」和「数字人页清单」，发给我复核；确认前不要生成。
```

确认后：

```text
脚本通过。数字人页确认：第 X、Y、Z 页。可以生成。
```

只要普通 PPT：

```text
不要数字人，只要普通可编辑 PPT
```

更细的口令见业务包：`08_`～`12_` 各模式文件夹里的 `口令卡.md`。

## 10. 出问题怎么回（直接复制改）

| 情况 | 对 WorkBuddy 说 |
|------|------------------|
| 联合用药多了一行空的 | 「联合用药我只交了 2 组，请删掉第三空行后重出初稿」 |
| 功效被改写了 | 「第 2 节功效改成附件/我下面这段审核稿原文，再出」 |
| 还没有包装图 | 「包装下周才有，先槽位出初稿，成片等我补图」 |
| 模板选错了 | 「不要用课件4，改用绿色单品 5 页结构，重出初稿」 |
| 安装过期/行为怪 | 「请 git pull 拉最新，然后指引我使用」 |

完整核对项见：`业务验收清单.md`。

## 12. 你不需要关心的

- 工程源码、`node_modules`、命令行脚本  
- 空白 Word、填写参考 docx（业务包**不向业务提供**这些流程）  
- 自由拼构件、自己配版式  

默认路径：**业务在 WorkBuddy 本机自助**；只有异常/新页型才找制作。
