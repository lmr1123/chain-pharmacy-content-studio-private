# 一页怎么用（内部培训课件 / 视频）

## 安装

```text
请安装 https://github.com/lmr1123/chain-pharmacy-content-studio.git，然后指引我使用
```

## 三步（普通 PPT / 视频）

### 1. 看模板

打开引导页（一行四个小卡片）→ 点看关键页预览 → 选用模板。

### 2. 输入培训内容

在 WorkBuddy 直接说主题和要点，例如：

```text
整理可可康灵芝胶囊商品，主要是围绕宁心安神助睡眠、提升免疫力、保肝护肝抗衰老3个方面来完善，你先整理符合内容再生成ppt
```

### 3. 下载与修改

可下载 PPT 修改，或输入指令批量修改，例如：

```text
第二页卖点改成…
批量把联合用药改成 2 条
```

## 数字人侧讲模式（可选 · 四步）

需要「关键页真人数字人出镜 + 其余页全宽讲解」时：

1. 安装/拉最新后说：**「这个课件用数字人模式」**  
2. 代理先出 **全课旁白脚本 + 数字人页清单**（写清第几页有数字人）  
3. **你确认后**才生成数字人（确认前不产生数字人费用）  
4. 收成片；要改再说  

详细：`08_数字人侧讲模式/README.md`  
口令：`08_数字人侧讲模式/口令卡.md`

```text
这个课件用数字人模式。请先整理旁白脚本和数字人页清单给我确认，确认前不要生成数字人。
```
